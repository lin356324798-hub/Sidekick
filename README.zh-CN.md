# Sidekick

**你的安卓设备，从今天起住进一个 AI agent。** 一个 Python 文件、零第三方依赖、浏览器当界面。

它不陪你聊天 —— 它**真的动手干活**：读写文件、跑命令、改代码、开网页、连手机、做表格、处理图片。

**不用服务器、不用账号、不用订阅。** 它跑在你自己的设备上，没有中间商 —— 想彻底离线，接个跑在局域网里的本地模型就行。

> `Sidekick` 只是出厂默认名，装好后可在「身份」页改成任何你喜欢的名字。

**语言：** [English](README.en.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [العربية](README.ar.md)

## 它跟别的 AI 有什么不一样

### 1. 两条命令装好 —— 快到你来不及泡杯茶

不用懂 Python，不用配环境，不用装数据库。装好 Termux，粘两行命令，浏览器打开就能用。**没有第 2.5 步，没有藏起来的坑。**

```bash
pkg install -y python curl
bash install.sh
```

没有 Docker、没有 Node、没有依赖冲突。**只用 Python 标准库**，所以上游更新搞不坏它 —— 今天能跑，三年后照样能跑。别人在修依赖，你在用它干活。

### 2. 它每天都在偷偷变强 —— 而你什么都不用做

这一点最特别：**它每天都自己变强一点，不需要任何人给你推更新包。**别人装软件是买回来那天最强，之后一路变旧；它是装回来那天最弱，之后一路变强。

它每天自动复盘自己的表现，挑出可改进的地方，改完写进日志。看几个它自己干的活：

| 日期 | 它自己改了什么 |
|---|---|
| 09-28 | `list_dir` 新增「按类型归档建议」—— 看文件时直接告诉你图片该放 `Pictures/`、文档该放 `Documents/` |
| 09-28 | 工具参数写错时，自动丢弃不支持的参数，并提示相近的正确名字（如 `cwd` → `command`） |
| 09-29 | `read_file` 遇到二进制文件不再吐满屏乱码，改为报告文件类型和大小 |
| 10-01 | 控制台卡片改固定高度 —— 因为实测发现切换标签时「保存」按钮会位移 447px，手指容易按空 |

> 这些不是宣传语，是它自己的进化日志原文。装到你机器上后，它会根据自己的使用情况长出**跟你有关**的改进。

**这意味着什么：** 你的 agent 和别人的 agent，用一个月后会长得**完全不一样**。你常让它整理相册，它就进化出更强的图片处理；你常拿它写报告，它就进化出更顺的文档流程。**每台设备养出来的都是独一无二的 —— 世界上不会有第二个跟你的一样。**

### 3. 崩了它自己爬起来 —— 你甚至能围观它怎么开刀

程序崩了不会只留个报错。它内置**自愈**机制：检测到崩溃 → 自己读日志定位 → 改代码 → 验证 → 记录归档。**凌晨三点崩的，天亮前它已经自己修好了 —— 你睡觉的时候它在干活。**

真实记录（来自 `selfheal.json`）：

```
10-01 14:22  发现崩溃    看门狗日志 · 指纹 f99407371b41
10-01 14:23  自愈完成    Confirmed — line 2809 是无关的日志读取代码，
                        且 tool_wx_auto 已定义，无需进一步修改
```

它甚至会**推翻错误判断**：另一次自愈的结论是「这不是待修复的 bug，文件已自我修复」，并列出证据链表格。它不瞎改。

改自己之前**先备份**，改完**做语法检查**，起不来**自动回滚**。所以「自己修自己」不等于「把自己搞死」。

### 4. 断线也能接着干 —— 长任务不怕中断

跑了半小时的任务，Termux 被系统杀了？重启后它**自动接着跑**，不用你重新交代一遍。

```bash
$ tail evolve.log
[自愈] 发现显式接续标记，自动继续跑一轮
[自愈] 自动续跑 20260928-034008-1058（boot），第 2 次
```

手机重启、切换网络、Termux 被清理 —— 它记得自己干到哪了。

:::tip 一句话总结

**装起来不费劲，用起来会长大，坏了会自己修，断了能接着干。**

:::

### 装完就能验证 —— 不用信我说

装好之后，直接看它自己的进化记录：

```bash
cat ~/.termux-agent/evolve.json     # 它每天为自己做了什么（含原因）
cat ~/.termux-agent/selfheal.json   # 它发现并修复过哪些崩溃
tail ~/.termux-agent/evolve.log     # 进化与自愈的实时日志
```

这些文件是它运行时**自己写**的，不是预先塞进去的宣传材料。你的设备上跑一段时间后，里面会长出属于你的记录。

## 它是什么

一个住在你手机/平板里的 AI 助手，通过浏览器界面使用。

**设计取舍**

| 原则 | 说明 |
|---|---|
| **零第三方依赖** | 只用 Python 标准库，`pkg install python` 即可运行。不碰任何需要编译的原生模块，因此永远不会因为上游升级而失修 |
| **本地存储** | 会话、记忆、密钥全在本机 `~/.termux-agent/`，不上传云端 |
| **能改自己** | 可以修改自己的源码来加功能，改坏了自动回滚 |
| **自带看门狗** | 服务挂了自动拉起，不依赖 systemd（安卓没有） |
| **无需远程升级** | 没有服务器、没有更新推送。它的进化由自己完成，功能增长不依赖作者发布新版 |

## 安装

前置：安卓设备装好 [Termux](https://f-droid.org/packages/com.termux/)（**建议用 F-Droid 版**，插件必须与主程序同签名）。

```bash
# 1. 装 Python
pkg update && pkg install -y python curl

# 2. 进入本目录，一键安装
bash install.sh
```

安装脚本会依次：检查环境 → 备份已有安装 → 拷贝程序与技能 → 生成默认配置（**不覆盖已有 API Key**）→ 启动服务并自检。

---

## 配置 API Key

首次运行需要填 API Key，两种方式：

**方式一（推荐）**：打开 `http://127.0.0.1:8765/`，右上角「设置」里填。

**方式二**：命令行
```bash
python3 ~/.termux-agent/agent.py config
```

默认接 DeepSeek（`https://api.deepseek.com`），也可换成任何兼容 OpenAI 格式的接口 —— 包括跑在你局域网里的本地模型。

## 日常使用

```bash
bash ~/.termux-agent/start.sh              # 重启 Termux 后恢复服务
python3 ~/.termux-agent/agent.py doctor    # 环境自检 + 连通性测试
python3 ~/.termux-agent/agent.py restart   # 重启服务
python3 ~/.termux-agent/agent.py selfcheck # 自我体检（源码/看门狗/服务/备份）
```

然后在浏览器打开 **http://127.0.0.1:8765/**。

### 命令行直用（不开界面）

```bash
python3 ~/.termux-agent/agent.py "看看磁盘占用"   # 跑一次就退出
python3 ~/.termux-agent/agent.py -c               # 续聊上次会话
python3 ~/.termux-agent/agent.py chat             # 终端里对话（简陋）
```

### 开机自启（可选）

装好 [Termux:Boot](https://f-droid.org/packages/com.termux.boot/)、先手动打开一次该 App，然后：

```bash
python3 ~/.termux-agent/agent.py autostart
```

## 工具详解（20 个）

### 系统与文件

| 工具 | 作用 | 亮点 |
|---|---|---|
| `bash` | 执行 shell 命令 | 主力工具，可装包、管理文件、跑程序 |
| `read_file` | 读文本文件（带行号） | 大文件分页读，`offset` 传负数可从末尾看日志结尾 |
| `write_file` | 整文件写入 | 自动建父目录 |
| `edit_file` | 精确字符串替换 | 要求唯一匹配；多处改动会提示行号供定位 |
| `apply_patch` | 多处/多文件补丁 | **原子生效**：任何一处对不上就整体不改，不会改一半 |
| `list_dir` | 列目录 | 含类型、大小、修改时间 |
| `grep` | 递归正则检索 | 返回 `文件:行号: 内容` |

### 联网

| 工具 | 作用 | 注意 |
|---|---|---|
| `fetch_url` | 抓网页/API 转纯文本 | 只适合读文本 |
| `web_search` | 联网搜索 | **无需 API Key** |
| `download` | 流式下载大文件 | 不截断、带超时、自动重试，适合 APK / 安装包 |

### 设备与外部系统

| 工具 | 作用 | 说明 |
|---|---|---|
| `sysshell` | 以 shell（adb）身份执行 | 权限高于普通应用，可读系统设置、`dumpsys`、`getprop`、`pm/am`。**不是 root** |
| `hdcmate` | 远程控制华为手机 | 走 HDC 协议（非 adb）。`exec` 执行命令 / `target` 记住地址 / `test` 测连接。可做完整 UI 自动化 |
| `github` | 操作 GitHub 仓库 | `list/repo/read/tree/clone/pull/push/create/search` 九个动作，需配 Token |
| `wps` | 生成 Word/Excel/PPT | 本地 MCP 服务实现，**不需要登录账号**，文件落在 `~/storage/shared/WPS_AI/` |
| `imgedit` | 图片 AI 处理 | 五种操作：`erase` 擦文字水印 / `restore` 老照片修复 / `enhance` 画质增强 / `beauty` 人像美化 / `matting` 抠图 |

### 协作与自我进化

| 工具 | 作用 | 说明 |
|---|---|---|
| `todo_write` | 维护任务清单 | 3 步以上的任务拆成 2~6 步，实时显示在你输入框上方，中断重连后据此续做 |
| `subagent` | 子代理独立思考 | 把独立子问题丢给它单独想（不接触本机文件），适合并行推进多个难点 |
| `ask_user` | 征询你的决策 | 弹出选择面板。只在必须由你拍板时用：花钱、删数据、方案取舍 |
| `selfupdate` | **修改自己** | 自动备份 + 语法检查，失败立即还原；成功后服务自动重启 |

### 已归档

| 工具 | 说明 |
|---|---|
| `wx_auto` | 微信自动陪聊（读屏 + 自动回复，需授权且对方知情）。含三道安全闸门：识别不准只记日志、找不到发送按钮就放弃、每小时上限 20 条 |

## 安全说明

- 界面**只监听 `127.0.0.1`**，不对局域网开放（界面含命令执行权限）
- `config.json`、Token 文件权限均为 `600`
- 格式化、直写块设备、删根目录等不可逆操作会被自动拦下
- 无 root 权限，也读不到其它应用的私有数据
- 环境自检：`python3 ~/.termux-agent/agent.py doctor`

## 常见问题

**服务起不来？**
```bash
python3 ~/.termux-agent/agent.py selfcheck   # 看它自己怎么说
tail -30 ~/.termux-agent/supervisor.log      # 看看门狗日志
```

**它真的会自己进化吗？进化了啥？**
看 `~/.termux-agent/evolve.json`，里面每条都记着改了什么、为什么改。命令行快速看：
```bash
python3 -c "import json;print('\n'.join(f'{e[\"time\"]}  {e[\"summary\"].splitlines()[0]}' for e in json.load(open('$HOME/.termux-agent/evolve.json'))['log']))"
```

**进化和远程升级有什么区别？**
不联网下载任何更新包，也没有服务器在推版本。它是**读自己的代码和日志，就地改**。所以每台设备养出来的能力不一样，取决于你怎么用它。

**它改自己代码，改崩了怎么办？**
走 `selfupdate` 通道会**先备份 → 改完做语法检查 → 失败立即还原**；即使新代码起来了但运行异常，看门狗也会回滚到上一版。自愈过程本身也会留下记录（`selfheal.json`）。

**长任务跑到一半被系统杀了？**
重启后自动接着跑，不用重新交代。日志里会出现「自动续跑」字样。

**改了代码不生效？**
新代码要先被浏览器加载一次才生效，刷新一下页面。

**想看它踩过哪些坑？**
`skills/termux-traps.md` 记录了这台设备上的各种环境陷阱。

**想加新能力？**
用 `skill-creator` 技能创建一个新的 `.md` 放进 `skills/`，或让 AI 用 `selfupdate` 给自己加工具。
