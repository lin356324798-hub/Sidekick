# Sidekick

**Локальный ИИ-агент, работающий прямо на вашем Android-устройстве.** Один файл Python, ноль сторонних зависимостей, браузер в роли интерфейса.

Он не просто общается — он **реально управляет вашим устройством**: читает и пишет файлы, выполняет команды, правит код, открывает веб-страницы, управляет телефоном, строит таблицы, обрабатывает изображения.

> `Sidekick` — лишь заводское имя по умолчанию. Переименуйте его как угодно на странице «Идентичность».

## Чем он отличается от других ИИ

### 1. Установка для любого — две команды, третьего шага нет

Не нужно знать Python. Не нужно настраивать окружение. Не нужна база данных. Установите Termux, вставьте две строки, откройте браузер — готово.

```bash
pkg install -y python curl
bash install.sh
```

Ни Docker, ни Node, ни конфликтов зависимостей. Он использует **только стандартную библиотеку Python**, поэтому обновления «сверху» не могут его сломать — работает сегодня, будет работать и через три года.

### 2. Он сам развивается каждый день — без обслуживания и без удалённых обновлений

Это самое необычное: **каждый день он становится чуть лучше, и никто не должен присылать вам обновление.**

Каждый день он анализирует собственную работу, находит, что можно улучшить, вносит изменение и записывает это в журнал. Вот реальная работа, которую он выполнил сам:

| Дата | Что он изменил сам |
|---|---|
| 09-28 | Добавил в `list_dir` подсказки «архивировать по типу» — при выводе списка файлов он теперь говорит, что изображения кладут в `Pictures/`, а документы в `Documents/` |
| 09-28 | При опечатке в аргументе инструмента он тихо отбрасывает неподдерживаемые аргументы и подсказывает ближайшее правильное имя (например, `cwd` → `command`) |
| 09-29 | `read_file` больше не выдаёт мусор на бинарных файлах, а сообщает тип и размер файла |
| 10-01 | Зафиксировал высоту карточки консоли — потому что тесты показали, что кнопка «Сохранить» смещалась на 447 px при переключении вкладок и по ней промахивались |

> Это не рекламные лозунги. Это выдержки из его собственного журнала эволюции. Запустите его у себя — и он вырастит улучшения, **относящиеся именно к вам**.

**Что это значит:** ваш агент и агент другого человека через месяц использования разойдутся. Если вы часто просите его разбирать фотоальбомы, он разовьёт более сильную обработку изображений. Если используете его для отчётов — разовьёт более плавный документооборот. **Каждое устройство выращивает уникального агента.**

### 3. Он сам исправляет свои ошибки — и вы можете наблюдать за диагностикой

Когда программа падает, он не оставляет лишь трассировку стека. У него встроен механизм **самовосстановления**: обнаружить падение → прочитать свои же логи и локализовать → исправить код → проверить → зафиксировать результат.

Реальная запись (из `selfheal.json`):

```
10-01 14:22  Обнаружено падение   лог сторожевого таймера · отпечаток f99407371b41
10-01 14:23  Восстановление готово Подтверждено — строка 2809 это посторонний
                                  код чтения логов, а tool_wx_auto определён.
                                  Дальнейшие правки не нужны.
```

Он даже **отменяет собственный ошибочный вывод**: в другом сеансе самовосстановления он заключил, что «это не ошибка, которую надо исправлять — файл уже сам себя починил», и изложил доказательства в таблице. Он не меняет код вслепую.

Перед изменением себя он **сначала делает резервную копию**, затем **прогоняет проверку синтаксиса**, а если не запускается — **автоматически откатывается**. Так что «чинит себя» не означает «калечит себя».

### 4. Продолжает с места остановки — долгие задачи переживают прерывания

Получасовая задача, и Android убил Termux? После перезапуска он **автоматически продолжает**, без необходимости объяснять всё заново.

```bash
$ tail evolve.log
[самовосстановление] Найден явный маркер продолжения; продолжаю автоматически
[самовосстановление] Возобновляю 20260928-034008-1058 (boot), попытка 2
```

Перезагрузка телефона, смена сети, выгрузка Termux системой — он помнит, на чём остановился.

---

:::tip Одной фразой

**Легко установить, растёт при использовании, чинит себя при поломке, продолжает после обрыва.**

:::

### Проверьте сами — не верьте мне на слово

После установки посмотрите его собственные журналы эволюции:

```bash
cat ~/.termux-agent/evolve.json     # что он улучшил для себя и почему
cat ~/.termux-agent/selfheal.json   # какие падения нашёл и исправил
tail ~/.termux-agent/evolve.log     # живой лог эволюции и самовосстановления
```

Эти файлы **пишет сам агент во время работы**, это не заранее заготовленный рекламный материал. Поработает немного — и они наполнятся записями, принадлежащими вам.

## Что это такое

ИИ-ассистент, живущий в вашем телефоне или планшете и используемый через интерфейс браузера.

**Проектные решения**

| Принцип | Пояснение |
|---|---|
| **Ноль сторонних зависимостей** | Использует только стандартную библиотеку Python; достаточно `pkg install python`. Никаких нативных модулей с компиляцией, поэтому обновления «сверху» никогда его не сломают |
| **Локальное хранение** | Диалоги, память и ключи остаются в `~/.termux-agent/` на вашем устройстве. Ничего не отправляется в облако |
| **Может менять себя** | Он может править собственный исходный код, добавляя функции, и автоматически откатывается, если правка ломает систему |
| **Со сторожевым таймером** | Если служба умирает, она автоматически перезапускается, без systemd (которого в Android нет) |
| **Удалённые обновления не нужны** | Ни сервера, ни рассылки обновлений. Его эволюция самостоятельна; новые возможности не зависят от выпуска версии автором |

## Установка

Предварительно: установите [Termux](https://f-droid.org/packages/com.termux/) на Android-устройство (**рекомендуется версия из F-Droid** — дополнения должны иметь ту же подпись, что и основное приложение).

```bash
# 1. Установить Python
pkg update && pkg install -y python curl

# 2. Из этого каталога запустить установщик
bash install.sh
```

Установщик по порядку: проверит окружение → сохранит резервную копию существующей установки → скопирует программу и навыки → создаст конфигурацию по умолчанию (**не перезаписывая существующий ключ API**) → запустит службу и выполнит самопроверку.

---

## Настройка ключа API

При первом запуске нужен ключ API. Два способа:

**Способ 1 (рекомендуется)**: откройте `http://127.0.0.1:8765/` и заполните его в «Настройках» в правом верхнем углу.

**Способ 2**: из командной строки
```bash
python3 ~/.termux-agent/agent.py config
```

По умолчанию используется DeepSeek (`https://api.deepseek.com`), но можно указать любую совместимую с OpenAI конечную точку — включая локальную модель в вашей сети.

## Повседневное использование

```bash
bash ~/.termux-agent/start.sh              # восстановить службу после перезапуска Termux
python3 ~/.termux-agent/agent.py doctor    # проверка окружения + тест связи
python3 ~/.termux-agent/agent.py restart   # перезапустить службу
python3 ~/.termux-agent/agent.py selfcheck # самодиагностика (исходник/сторож/служба/копии)
```

Затем откройте в браузере **http://127.0.0.1:8765/**.

### Прямое использование из командной строки (без интерфейса)

```bash
python3 ~/.termux-agent/agent.py "проверь занятое место"   # выполнить разово и выйти
python3 ~/.termux-agent/agent.py -c                       # продолжить последний диалог
python3 ~/.termux-agent/agent.py chat                     # общение в терминале (простое)
```

### Автозапуск при загрузке (необязательно)

Установите [Termux:Boot](https://f-droid.org/packages/com.termux.boot/), один раз откройте это приложение вручную, затем:

```bash
python3 ~/.termux-agent/agent.py autostart
```

## Справочник инструментов (20)

### Система и файлы

| Инструмент | Назначение | Особенности |
|---|---|---|
| `bash` | Выполнение команд shell | Рабочая лошадка: установка пакетов, работа с файлами, запуск программ |
| `read_file` | Чтение текстовых файлов (с номерами строк) | Постраничное чтение больших файлов; отрицательный `offset` читает логи с конца |
| `write_file` | Запись файла целиком | Автоматически создаёт родительские каталоги |
| `edit_file` | Точная замена строки | Требует единственного совпадения; при нескольких сообщает их номера строк |
| `apply_patch` | Патч по нескольким местам / файлам | **Атомарно**: если хоть один фрагмент не совпал, ничего не записывается — без половинчатых правок |
| `list_dir` | Список каталога | Включает тип, размер, время изменения |
| `grep` | Рекурсивный поиск по регулярному выражению | Возвращает `файл:строка: содержимое` |

### Сеть

| Инструмент | Назначение | Примечания |
|---|---|---|
| `fetch_url` | Получить страницу/API как обычный текст | Только чтение текста |
| `web_search` | Веб-поиск | **Ключ API не нужен** |
| `download` | Потоковая загрузка больших файлов | Без обрезки, с таймаутом и авто-повтором. Подходит для APK и установщиков |

### Устройства и внешние системы

| Инструмент | Назначение | Примечания |
|---|---|---|
| `sysshell` | Выполнение от имени shell (adb) | Права выше, чем у обычного приложения: чтение системных настроек, `dumpsys`, `getprop`, `pm/am`. **Не root** |
| `hdcmate` | Удалённое управление телефоном Huawei | Использует протокол HDC (не adb). `exec` выполняет команду / `target` запоминает адрес / `test` проверяет связь. Возможна полная автоматизация интерфейса |
| `github` | Работа с репозиториями GitHub | Девять действий: `list/repo/read/tree/clone/pull/push/create/search`. Нужен токен |
| `wps` | Генерация Word/Excel/PPT | Реализовано локальной службой MCP, **без входа в аккаунт**. Файлы появляются в `~/storage/shared/WPS_AI/` |
| `imgedit` | ИИ-обработка изображений | Пять операций: `erase` текст/водяной знак / `restore` старые фото / `enhance` качество / `beauty` портрет / `matting` вырезание фона |

### Совместная работа и самоэволюция

| Инструмент | Назначение | Примечания |
|---|---|---|
| `todo_write` | Ведение списка задач | Дробит задачи из 3+ шагов на 2–6 пунктов, показываемых вживую над полем ввода; после переподключения продолжает с этого места |
| `subagent` | Независимое рассуждение суб-агента | Передаёт изолированную подзадачу отдельному агенту (без доступа к локальным файлам). Удобно распараллеливать сложные задачи |
| `ask_user` | Запрос решения у вас | Открывает панель выбора. Используется только когда решение за вами: трата денег, удаление данных, выбор подхода |
| `selfupdate` | **Изменить себя** | Автосохранение + проверка синтаксиса, мгновенный откат при сбое; при успехе служба перезапускается автоматически |

### В архиве

| Инструмент | Примечания |
|---|---|
| `wx_auto` | Компаньон автоответов в WeChat (чтение экрана + автоответ; нужны авторизация и осведомлённость второй стороны). Три предохранителя: неясные распознавания только логируются, при ненайденной кнопке отправки он отступает, и не более 20 сообщений в час |

Навыки — это **методологические документы по предметным областям**, передаваемые ИИ. Перед соответствующей задачей он читает нужный навык и следует заложенным в нём правилам и накопленному опыту.

## О безопасности

- Интерфейс **слушает только `127.0.0.1`** и не открыт в локальную сеть (у интерфейса есть права на выполнение команд)
- `config.json` и файлы токенов имеют права `600`
- Необратимые операции — форматирование, прямая запись на блочные устройства, удаление корневого каталога — перехватываются автоматически
- Нет прав root, и он не может читать приватные данные других приложений
- Самопроверка окружения: `python3 ~/.termux-agent/agent.py doctor`

## Частые вопросы

**Служба не запускается?**
```bash
python3 ~/.termux-agent/agent.py selfcheck   # посмотреть, что он сам скажет
tail -30 ~/.termux-agent/supervisor.log      # проверить лог сторожевого таймера
```

**Он правда сам развивается? Что он изменил?**
Смотрите `~/.termux-agent/evolve.json` — в каждой записи указано, что изменено и почему. Быстрый просмотр из командной строки:
```bash
python3 -c "import json;print('\n'.join(f'{e[\"time\"]}  {e[\"summary\"].splitlines()[0]}' for e in json.load(open('$HOME/.termux-agent/evolve.json'))['log']))"
```

**Чем самоэволюция отличается от удалённого обновления?**
Он не скачивает пакеты обновлений, и никакой сервер не рассылает ему версии. Он **читает собственный код и логи и правит их на месте**. Поэтому возможности различаются от устройства к устройству — зависит от того, как вы им пользуетесь.

**А если он сломает себя при правке своего кода?**
Канал `selfupdate` **сначала делает резервную копию → проверяет синтаксис после правки → немедленно восстанавливает при сбое**. Даже если новый код запустится, но поведёт себя неверно, сторожевой таймер откатит к предыдущей версии. Сам процесс самовосстановления тоже оставляет запись (`selfheal.json`).

**Долгую задачу убили на середине?**
После перезапуска она продолжится автоматически; ничего заново объяснять не нужно. В логе появится «возобновляю».

**Я изменил код, но ничего не произошло?**
Новый код вступает в силу только после того, как браузер загрузит его один раз — просто обновите страницу.

**Где посмотреть, на какие грабли он наступал?**
`skills/termux-traps.md` описывает ловушки окружения на таких устройствах.

**Как добавить новые возможности?**
Используйте навык `skill-creator`, чтобы создать новый `.md` в `skills/`, или позвольте ИИ добавить себе инструмент через `selfupdate`.
