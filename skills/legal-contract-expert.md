# legal-contract-expert

> L2 法律合同专家。覆盖各类合同、协议、条款、契约的起草与审查，包含必备条款完整性检查（标的/价款/违约/争议解决/生效条件）、权利义务对称性审核、高风险点防范（不可抗力/知识产权归属/保密期限）。采用严格 Critic 审查，涉及法律责任任务**强制**走 per-section 模式分章审查。触发关键词：合同、契约、协议、条款、甲乙方、违约金、不可抗力、争议解决。

## 使用说明（重要）

本技能从 WorkBuddy 导入。文中若提到 WorkBuddy 专有工具（如 `present_files`、`show_widget`、MCP 连接器、宿主图像/视频生成、腾讯文档授权、云端资料库等），这些在**本机（Sidekick / Termux）上并不存在**。遇到这类步骤，请改用本机已有能力实现，或直接跳过并说明原因。

### Phase 1 — 主题理解

你需要详细思考如下要点：
1. **合同类型识别**（技术服务 / 买卖 / 租赁 / 劳务 / NDA / 框架协议 / 其他）→ 查询 `experts/legal-contract-expert/references/terms-library.md` 确认本类型对应的法律依据与必备条款清单。
2. **当事人画像**：甲乙方身份（自然人 / 公司 / 政府机构）、是否存在多方、是否涉及境外主体。
3. **核心商业条款 5-8 条**：标的物/服务、价款/费用、履行期限、验收标准、违约责任、争议解决、保密与知识产权、生效条件。
4. **高风险点识别**：对方违约风险、不可抗力场景、知识产权归属、数据合规、跨境合规等。

保存到 `output/params/topic.yaml`：

```yaml

target_length: 4500
target_tone: "正式法律文书，第三人称，中立客观"
contract_type: "technical_service"          # 合同类型枚举
parties: ["甲方：XX公司", "乙方：XX公司"]
governing_law: "《民法典》合同编 + 相关行业特别法"
mandatory_clauses:                          # 本类型必备条款清单（来自 references）
  - 合同标的
  - 价款与支付
  - 履行期限
  - 验收标准
  - 违约责任
  - 争议解决
  - 生效条件
risk_level: "high"                           # 法律合同默认 high
```

### references/anti-patterns.md

# 法律合同反直觉案例库（Anti-Patterns）

> 本文件是 L2 法律合同专家的**对抗审查尺规**，由 Critic 引擎在 Adversarial Critic 阶段**强制加载**。
>
> 每条 Anti-Pattern 都是从真实案例/专家经验中蒸馏的"**如果不这样做，就会出大事**"的反直觉规则。

---

## 一、 必备条款完整性（Critical）

这一类扣分最重，**缺一项 = 立即扣 30 分**。

### AP-001：标的条款必须具体化
- ❌ 反例："甲方委托乙方完成相关工作"
- ✅ 正例："甲方委托乙方开发《订单管理系统 V1.0》，功能清单详见附件一，技术要求详见附件二"
- **扣分原则**：标的不明确，后续履约无法确认，扣 30 分。

### AP-002：价款与支付方式必须明确
- 必须包含：**总金额、币种、支付节点、支付方式、发票类型**五要素。
- 缺任一要素扣 10 分，累计扣至 30 分封顶。

### AP-003：违约责任条款必须具体到金额或比例
- ❌ 反例："违约方应赔偿相关损失"
- ✅ 正例："违约方应按合同总金额 20% 支付违约金；给对方造成的实际损失超过违约金的，超过部分另行赔偿"
- **扣分**：未具体化扣 20 分。

### AP-004：争议解决条款必须二选一明确
- 必须明确选择：**诉讼**（指定管辖法院）或 **仲裁**（指定仲裁委员会）。
- 未明确、或两者并存、或约定模糊，扣 20 分。

### AP-005：合同生效条件
- 必须包含生效方式：**自签字盖章之日起生效** / **自 XX 日起生效** / **自满足 XX 条件时生效**。
- 缺失扣 10 分。

---

## 二、 风险防范（High）

### AP-101：不可抗力条款必须约定通知期限
- **常见错误**：只说"发生不可抗力时免责"，但不约定通知对方的期限。
- **正确做法**："不可抗力发生后 X 日内书面通知对方，并在合理时间内提供有效证明"。
- **扣分**：未约定通知期限扣 15 分。

### AP-102：知识产权归属必须明确
- 涉及定制开发、创作、设计类合同，**必须**明确：
  - 开发/创作过程中产生的 IP 归属（甲方 / 乙方 / 共有）
  - 是否包含对既有 IP 的使用授权
- **扣分**：未明确归属扣 25 分（此类纠纷极高发）。

### AP-103：保密条款应约定保密期限
- ❌ 反例："双方应对合同内容永久保密"（过于绝对，实操难执行）
- ✅ 正例："保密期限为合同签订之日起至合同终止后 3 年"
- **扣分**：未约定或约定"永久"扣 10 分。

### AP-104：合同解除的条件与程序
- 必须区分：**协商一致解除** / **法定解除** / **约定解除**。
- 约定解除需列明具体情形（如：累计违约 X 次、迟延履行超过 X 日）。
- **扣分**：未列具体情形扣 15 分。

### AP-105：通知与送达条款
- 必须约定双方的**通知地址、联系方式、通知到达的认定标准**。
- 尤其注意电子送达（邮件/短信）的法律效力条款。
- **扣分**：缺失扣 10 分。

---

## 三、 权利义务对称性（Medium）

### AP-201：禁止单方面过度倾斜
- 检查项：甲方权利条款数量 vs 乙方权利条款数量。
- **预警**：若某一方权利条款多出对方 50% 以上，且未通过对价平衡，扣 10 分。

### AP-202：甲乙方定义必须一致
- 通篇检查"甲方"、"乙方"的指代不能错位。
- **扣分**：出现指代混乱扣 5 分/处。

### AP-203：数字与金额须大小写并列
- 所有合同金额、违约金、期限天数，必须同时用**阿拉伯数字 + 中文大写**。
- 例："人民币壹拾万元整（¥100,000）"
- **扣分**：未大小写并列扣 5 分/处。

---

## 四、 表述规范性（Low）

### AP-301：禁用口语化、情绪化表达
- ❌ 禁用词：基本上、差不多、大概、尽量、可能
- ✅ 应使用：应、应当、不得、必须、不迟于
- **扣分**：每处扣 2 分。

### AP-302：时间表述须精确
- ❌ "尽快"、"合理时间"、"及时"
- ✅ "自合同签订之日起 X 个工作日内"
- **扣分**：模糊时间每处扣 3 分。

### AP-303：禁用"等等"、"之类"的开放式列举
- 法律文书的列举必须闭合，使用"包括但不限于"后必须枚举具体项。
- **扣分**：每处扣 2 分。

---

## 五、 评分计算公式

```
最终得分 = 100 - Σ(扣分项) + 加分项

加分项（最多 +10 分）：
- 附加履约担保条款：+5
- 附加争议解决前置调解程序：+3
- 附加合规性承诺（反商业贿赂、数据安全）：+2
```

**通过阈值**：总分 ≥ 85。低于阈值必须进入重写循环。

# 法律合同术语规范库（Terms Library）

> 本文件是 L2 法律合同专家的**术语对齐清单**。Critic 引擎在审查时必须对照本库，确保合同中的法律术语使用规范、准确。

---

## 一、 主体称谓

| 规范术语 | 使用场景 | 禁用替代 |
| --- | --- | --- |
| 甲方 / 乙方 / 丙方 | 通用双（多）方合同 | 您方 / 我方 / 你们 |
| 委托方 / 受托方 | 委托合同 | 雇主 / 帮忙的人 |
| 出卖人 / 买受人 | 买卖合同 | 卖家 / 买家 |
| 出租人 / 承租人 | 租赁合同 | 房东 / 租客（在合同正文中） |
| 发包人 / 承包人 | 建设工程、承揽合同 | 甲 / 乙（除非已在首部定义） |
| 许可人 / 被许可人 | 知识产权许可 | 授权方 / 获授权方（非正式） |

---

## 二、 履约动词

| 规范术语 | 含义 | 禁用替代 |
| --- | --- | --- |
| 应 / 应当 | 强制性义务（违反构成违约） | 必须 / 一定要 / 得 |
| 不得 | 禁止性义务 | 不能 / 不行 / 不可以 |
| 可以 | 权利性选择（可选可不选） | 能 / 允许 / 有权 |
| 有权 | 明确赋权，可主动行使 | 能够 / 可以主动 |
| 负有 | 承担特定责任 | 要承担 / 负责 |
| 不迟于 | 期限截止前完成 | 在...之前 / 尽快在 |

## 四、 关键法律术语

### 4.1 违约与救济
| 规范术语 | 定义 |
| --- | --- |
| 违约 | 未按约定履行合同义务 |
| 违约金 | 约定的违约赔偿金额或比例 |
| 损失赔偿 | 违约金不足以弥补实际损失时的补充赔偿 |
| 继续履行 | 要求违约方按原约定继续履行 |
| 解除合同 | 终止合同关系的救济方式 |
| 定金罚则 | 给付定金一方违约丧失定金；收受定金一方违约双倍返还 |

### 4.2 不可抗力
| 规范术语 | 说明 |
| --- | --- |
| 不可抗力 | 不能预见、不能避免且不能克服的客观情况 |
| 情势变更 | 合同订立后客观情况发生重大变化（区别于不可抗力） |
| 免责事由 | 因不可抗力导致不能履行的部分或全部免责 |

### 4.3 争议解决
| 规范术语 | 说明 |
| --- | --- |
| 友好协商 | 争议解决的前置程序 |
| 仲裁 | 由约定的仲裁委员会裁决（一裁终局） |
| 诉讼 | 向约定管辖法院提起诉讼（两审终审） |
| 管辖 | 明确争议解决的地域与层级 |

### 4.4 保密与知识产权
| 规范术语 | 说明 |
| --- | --- |
| 保密信息 | 需明确列举或通过标识界定 |
| 保密期限 | 保密义务的有效期（建议 3-5 年） |
| 职务作品 | 员工因履行职务完成的作品（归单位） |
| 委托作品 | 委托创作完成的作品（著作权归属依约定） |
| 独占许可 | 仅被许可人可使用，许可人也不得使用 |
| 排他许可 | 许可人 + 被许可人可使用，不得再授权第三方 |
| 普通许可 | 被许可人可使用，许可人可再授权多方 |

## 五、 引用法律的标准格式

