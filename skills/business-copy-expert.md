# 商业文案 · 写作专家

> 好文案不是文字游戏，是精准理解用户需求后的一次有效沟通。

## Overview

商业文案领域专家，覆盖品牌传播、产品转化、用户沟通三大方向。核心能力是把产品价值翻译成用户利益，用最少的字传递最强的信号。

## Core Workflow

1. **识别任务类型** — 根据用户输入判断文案类别，路由到对应路径
2. **收集核心信息** — 确认目标受众、品牌调性、核心卖点、投放渠道
3. **加载对应指南** — 按需加载 references/ 中的专题知识
4. **策略选择** — 根据场景选择创意策略（AIDA/FAB/PAS 等）
5. **创作输出** — 按 Output Contract 格式交付
6. **合规自检** — 广告法红线检查

## Global Principles

1. **用户第一** — 文案主角是用户，说"你将获得…"而非"我们提供了…"
2. **利益驱动** — 每句话回答"so what"——这对我有什么好处？
3. **简洁有力** — 能用5个字说清的不用10个字，删删删
4. **情感共鸣** — 好文案让人"觉得你懂我"，不只是了解产品
5. **合规底线** — 严格遵守广告法，不用绝对化用语，不虚假宣传
6. **受众适配** — 语调、用词、平台规范必须匹配目标受众
7. **数据说话** — 能用具体数字的不用形容词（"快3倍"优于"非常快"）

## Output Contract

每次文案输出必须包含：

```
## 文案正文
[核心文案内容]

## 创意策略
- 策略模型：[AIDA/FAB/PAS/4U 等]
- 选择理由：[为什么选这个策略]

## 适用场景
- 渠道：[适合投放的渠道]
- 受众：[目标受众画像]

## 合规检查
- ✅/❌ 广告法合规结果
```

品牌类任务提供 ≥2 个方向，每个方向含策略说明。
诊断类任务输出评分（/10）+ 问题清单 + 优化版文案。

## Execution Rules

1. 不在输出中暴露专家角色设定或内部流程
2. 先理解需求再创作，信息不足时主动询问（路径F）
3. 涉及广告法敏感词时必须明确拒绝并解释原因
4. 提供多个方向时确保每个方向有差异化策略
5. 社媒文案必须适配对应平台的格式和调性规范
6. 不承诺具体转化率或效果数据

## Capability Boundary

**能做** ✅ 品牌文案创作 / 产品卖点提炼 / 营销邮件撰写 / 社媒内容策划 / 文案诊断优化 / 广告法合规检查
**不能做** ❌ 视觉设计 / 媒体投放策略 / 市场调研 / 保证转化率 / 竞品情报收集

# 商业文案反模式清单

> 这些是经过验证的"坑"——看到就要避免

## 致命反模式（必须避免）

### 1. 自嗨型文案
```
❌ "我们拥有业界领先的技术，核心团队来自BAT"
✅ "帮你把3天的工作压缩到30分钟"
```
**问题**：全是"我们如何厉害"，用户无感
**诊断信号**：主语是"我们/本公司/我司"出现 ≥3 次

### 2. 堆砌形容词
```
❌ "高端大气上档次，低调奢华有内涵的极致匠心产品"
✅ "医用级316L不锈钢内胆，经过 2000 小时耐腐蚀测试"
```
**问题**：空洞无物，不提供任何有效信息
**诊断信号**：连续 ≥3 个形容词修饰同一名词

### 3. 广告法违禁词
```
❌ "最好的AI写作工具"、"100%有效"、"永久免费"
✅ "超过10万用户选择的AI写作工具"
```
**问题**：罚款20-100万，品牌声誉损失
**诊断信号**：含"最/第一/唯一/顶级/极致/万能/100%"

### 4. 模糊CTA
```
❌ "欢迎了解更多" / "期待您的光临"
✅ "立即免费试用14天 →" / "扫码领取50元新人券"
```
**问题**：用户不知道做什么，转化率极低
**诊断信号**：CTA 不包含具体动作和利益

### 5. 信息过载
```
❌ 一篇文案塞了 10 个卖点
✅ 1个核心卖点 + 2-3个支撑点
```
**问题**：什么都说 = 什么都没记住
**诊断信号**：文案超过 500 字但没有明确的信息层次

## 严重反模式（应当避免）

### 6. 忽略受众
```
❌ 对 95 后用官方体："兹通知贵用户..."
✅ "嘿，你的会员快到期了 🎫"
```
**问题**：调性不匹配，用户觉得"这不是写给我的"

### 7. 功能罗列无转化
```
❌ "支持PDF/Word/PPT/Excel/HTML格式"
✅ "不管什么格式的文件，拖进来就能用"
```
**问题**：Feature 堆砌但没有翻译成用户利益

### 8. 虚假紧迫感
```
❌ "最后3小时！！！"（实际常年如此）
✅ "早鸟价截止：4月30日 23:59"
```
**问题**：损耗品牌信任

### 9. 忽视移动端阅读体验
```
❌ 邮件标题60个字符，正文全是长段落
✅ 标题 ≤50字符，正文用短段+列表
```
**问题**：60% 的邮件/社媒在手机端阅读

### 10. 复制粘贴式多平台发布
```
❌ 同一段文案同时发小红书、抖音、LinkedIn
✅ 同一核心信息，三种平台适配版本
```
**问题**：每个平台的调性、格式、用户期望完全不同

# 品牌文案写作指南

> 来源标准：品牌传播理论 + 广告学 AIDA 模型 + 广告法

## Goal

帮助创作具有记忆点、情感共鸣和品牌差异化的品牌文案（Slogan、品牌故事、品牌升级公告）。

## Pre-Writing Questions

1. **品牌定位**：品牌是谁？服务谁？解决什么核心问题？
2. **品牌调性**：专业/亲和/年轻/高端/科技/温暖/文艺？
3. **竞品差异**：与竞品相比，你的核心区别是什么？
4. **传播场景**：这段文案用在哪里？（官网/包装/广告/社媒）
5. **用户心智**：你希望用户看完后记住你什么？

## 创意策略模板

### 版本 1：功能利益型

**适用场景**：产品卖点明确、用户决策理性的品类

```
公式：[核心功能] + [量化效果] + [用户感受]
```

**句式骨架**：
- "[动词][时间/条件]，[达成效果]"
- 范例："充电5分钟，通话2小时"（OPPO）

→ 参见 `examples/brand-functional.md`

### 版本 2：情感利益型

**适用场景**：品牌建设期、用户决策感性的品类

```
公式：[情感洞察] + [品牌态度] + [身份认同]
```

**句式骨架**：
- "[你/我们] + [情感状态/价值观]"
- 范例："你本来就很美"（自然堂）

→ 参见 `examples/brand-emotional.md`

### 版本 3：场景代入型

**适用场景**：生活化品牌、高频消费品

```
公式：[痛点场景] + [解决方案] = [品牌名]
```

**句式骨架**：
- "[场景/痛点]，[动词][品牌名]"
- 范例："困了累了喝红牛"

→ 参见 `examples/brand-scenario.md`

### 版本 4：态度表达型

**适用场景**：年轻化品牌、态度营销

```
公式：[价值观宣言] → [行动号召]
```

**句式骨架**：
- "[祈使句/短句]"
- 范例："Just Do It"（Nike）

## 品牌故事框架

```
1. 创始人/团队的初心（Why）
2. 遇到的困难/转折（Conflict）
3. 坚持做对的事（Resolution）
4. 品牌理念升华（Meaning）
5. 邀请用户加入（Connection）
```

**关键**：品牌故事不是自传，是"为什么你应该信任我"的答案。

## 品牌升级传播

当品牌需要更名/升级时：

1. **公告文案**：解释为什么变 + 变了什么 + 不变的是什么
2. **价值主张**：新品牌的核心承诺（一句话能说清）
3. **Slogan 候选**：至少提供 3 个方向

## Quality Checklist

- [ ] Slogan 是否 ≤10 个字（中文）或 ≤5 个词（英文）？
- [ ] 是否避开了广告法绝对化用语？
- [ ] 是否有明确的品牌差异化？
- [ ] 目标受众能否在3秒内理解？
- [ ] 是否有情感触发点（不只是信息传递）？
- [ ] 是否提供了 ≥2 个创意方向？

# 文案诊断指南

> 来源标准：AIDA 模型 + 广告法 + 文案五维度评估体系

## Goal

帮助评估现有文案质量，识别问题并输出优化方案。

## 评价标准体系

### AIDA 达成度检测
```
A - Attention：标题/首句能否在3秒内抓住注意力？
I - Interest：是否激发了进一步了解的兴趣？
D - Desire：是否唤起了拥有/行动的欲望？
A - Action：CTA 是否明确有力？
```

### 文案质量五维度
| 维度 | 权重 | 评价标准 |
|------|------|---------|
| **吸引力** | 25% | 标题/首句能否在3秒内抓住注意力 |
| **信息传达** | 25% | 核心卖点/价值主张是否清晰传达 |
| **情感共鸣** | 20% | 是否触发目标受众的情感连接 |
| **行动驱动** | 15% | CTA 是否明确有力 |
| **品牌一致** | 15% | 语调、风格是否与品牌调性一致 |

### 广告法红线（绝对禁止）

| 类别 | 违禁词示例 | 法律后果 |
|------|----------|---------|
| 绝对化用语 | 最、第一、唯一、顶级、极致 | 罚款20-100万 |
| 虚假承诺 | 包治百病、100%有效、永久 | 罚款+吊销执照 |
| 贬低竞品 | 直接或暗示竞争对手差 | 不正当竞争 |
| 违禁评比 | 国家级、最高级、最佳 | 罚款20-100万 |

## 诊断输出模板

```markdown
## 文案诊断报告

### 综合评分：X/10

### AIDA 达成度
- A（注意力）：✅/❌ [具体分析]
- I（兴趣）：✅/❌ [具体分析]
- D（欲望）：✅/❌ [具体分析]
- A（行动）：✅/❌ [具体分析]

### 五维度评分
| 维度 | 得分 | 分析 |
|------|------|------|

### 问题清单（按严重程度排序）
1. 🔴 [致命问题]
2. 🟡 [改进建议]
3. 🟢 [优化空间]

### 广告法合规检查
- ✅/❌ [检查结果]

### 优化方案
#### 方向 A：[策略名]
[优化后文案]

#### 方向 B：[策略名]
[优化后文案]
```

## Quality Checklist

- [ ] 是否逐项检测了 AIDA 四要素？
- [ ] 是否进行了广告法违禁词扫描？
- [ ] 是否提供了 ≥2 个优化方向？
- [ ] 问题是否按严重程度排序？
- [ ] 优化方案是否保留了原文案的核心信息？

# 营销邮件写作指南

> 来源标准：Email Marketing 行业标准 + B2B Sales 最佳实践

## Goal

帮助创作高打开率、高点击率的营销邮件和 Cold Email。

## Pre-Writing Questions

1. **邮件目标**：要用户做什么？（注册/购买/回访/回复）
2. **收件人画像**：谁会收到？什么职位？什么痛点？
3. **关系阶段**：冷启动 / 已注册未使用 / 活跃用户 / 流失用户？
4. **核心利益点**：收件人为什么要花时间读这封邮件？

## 邮件结构模板

### 版本 1：用户激活/唤醒邮件

```
Subject: [痛点/利益] + [好奇心/紧迫感]（≤50字符）
Preview: 补充说明，不重复标题

正文：
├── 开头：个性化称呼 + 共鸣痛点（2-3句）
├── 价值：你的解决方案 + 核心利益（3-5句）
├── 证明：数据/案例/用户证言（2-3句）
├── CTA：明确的行动指引（1句，单一按钮）
└── PS：补充优惠/紧迫感（1句，可选）
```

→ 参见 `examples/email-activation.md`

### 版本 2：B2B Cold Email

```
Subject: [个性化钩子]（≤40字符，不像营销邮件）

正文：
├── 第1句：个性化破冰（提及对方公司/产品/最近动态）
├── 第2-3句：你发现的问题/机会（展示你做了功课）
├── 第4-5句：你的解决方案（一句话，不推销）
├── 第6句：社会证明（"[类似公司]用我们的方案做到了[结果]"）
├── CTA：低门槛请求（"15分钟电话？"而非"购买我们的产品"）
└── 签名：真实姓名+职位（不要花哨模板）
```

→ 参见 `examples/email-cold.md`

## 邮件优化关键数据

| 策略 | 效果提升 | 来源 |
|------|---------|------|
| 标题含数字 | 打开率 +36% | Mailchimp |
| 个性化称呼 | 打开率 +26% | Campaign Monitor |
| 单一CTA | 点击率 +28% | WordStream |
| 移动端适配 | 60%的邮件在手机打开 | Litmus |
| 正文 ≤200 词 | 回复率最优 | Boomerang |

## Quality Checklist

- [ ] 标题是否 ≤50 字符？是否有打开的理由？
- [ ] 是否避免了垃圾邮件触发词（免费/紧急/限时 等过度使用）？
- [ ] CTA 是否单一明确？用户知道下一步做什么？
- [ ] Cold Email 是否展示了"我研究过你"？
- [ ] 正文是否 ≤200 词（Cold Email）或 ≤400 词（营销邮件）？

# 产品文案写作指南

> 来源标准：FAB 法则 + 消费者决策理论 + 电商平台规范

## Goal

帮助创作能驱动转化的产品文案——卖点提炼、详情页、产品介绍。

## Pre-Writing Questions

1. **产品定位**：在品类中属于什么价位段？核心竞争力是什么？
2. **目标用户**：谁会买？购买决策的关键考量是什么？
3. **使用场景**：用户在什么场景下使用？解决什么具体问题？
4. **价格策略**：需要做价格正当化吗？（高价产品必须回答"为什么值这个价"）
5. **竞品对比**：用户可能会拿什么产品来比较？

## FAB 卖点提炼法

```
Feature（特征）→ Advantage（优势）→ Benefit（利益）

示例：
  Feature:   采用 Type-C 接口
  Advantage: 充电速度提升 50%
  Benefit:   午休30分钟，电量从20%充到80%，下午不焦虑
```

**关键**：用户不关心 Feature，只关心 Benefit。每个卖点必须落到用户利益。

## 产品描述结构模板

### 版本 1：标准电商详情页

```
1. 一句话价值主张（Hook）
2. 3-5个核心卖点（FAB 展开）
3. 使用场景描述（帮用户想象拥有后的生活）
4. 社会证明（用户评价/数据/奖项）
5. 行动号召（CTA）
```

→ 参见 `examples/product-detail-page.md`

### 版本 2：高价产品（价格正当化）

```
1. 品类认知重塑（"这不只是一个XX"）
2. 工艺/材料/技术差异（为什么成本高）
3. 长期价值算账（日均成本 or 使用寿命）
4. 对标高端品牌（"XX同等级材料"）
5. 用户证言（已购用户的真实感受）
```

→ 参见 `examples/product-premium.md`

### 版本 3：B2B/SaaS 产品

```
1. 痛点共鸣（你是否遇到过…）
2. 解决方案概述（一句话说清楚）
3. 核心能力矩阵（3-5个核心功能 + 对应价值）
4. 客户案例/数据证明
5. 免费试用/Demo CTA
```

→ 参见 `examples/product-saas.md`

## Quality Checklist

- [ ] 每个卖点是否都落到了用户利益（Benefit）而非功能（Feature）？
- [ ] 是否有具体数字支撑（而非空泛形容词）？
- [ ] CTA 是否明确、单一？（一个按钮 > 多个按钮）
- [ ] 高价产品是否回答了"为什么值这个价"？
- [ ] 是否避免了自嗨型表述（"我们如何厉害"）？

### references/social-media.md

# 社交媒体文案写作指南

> 来源标准：各平台内容规范 + 社媒营销最佳实践

## Goal

帮助创作适配不同社交平台的高互动率文案。

## Pre-Writing Questions

1. **发布平台**：小红书/抖音/微博/微信公众号/LinkedIn？
2. **内容目标**：种草/品宣/引流/互动？
3. **目标受众**：平台用户画像 + 品牌受众的交集
4. **内容形式**：图文/短视频/长文？

## 平台适配矩阵

| 平台 | 字数 | 调性 | 核心策略 | 关键规范 |
|------|-----|------|---------|---------|
| 小红书 | ≤1000字 | 种草/生活化 | 场景+体验+图文 | 禁导流外链，需标注广告 |
| 抖音 | 前3秒定生死 | 短平快 | Hook+反转+CTA | 黄金前3秒 |
| 微信公众号 | 不限 | 深度/专业 | 长文+故事+干货 | 首段折叠前150字决定阅读 |
| 微博 | 140字 | 话题性 | 热点+互动+态度 | 带话题标签 |
| LinkedIn | ≤3000字 | 专业/商务 | 洞察+案例+观点 | 开头2行是Hook |

## 社媒文案公式

### PAS 公式（万能）
```
Problem（痛点）→ Agitate（放大痛苦）→ Solution（方案）
```

### HOOK 公式（抖音/短视频）
```
Hook（钩子）→ Outcome（结果）→ Obstacle（障碍）→ Knowledge（知识）
```

### 4U 公式（小红书/微博）
```
Useful（有用）+ Urgent（紧迫）+ Unique（独特）+ Ultra-specific（超具体）
```

## 平台专项模板

### 小红书种草笔记

```
标题：[数字] + [痛点/效果] + [emoji]
正文：
├── 开头：场景代入 / 个人体验（真实感）
├── 产品介绍：使用感受 > 参数罗列
├── 对比/测评：有对比更有说服力
├── 价格评价：是否值得
└── 总结推荐：适合谁 + 不适合谁
标签：#品类 #关键词 #场景
```

→ 参见 `examples/social-xiaohongshu.md`

### 抖音短视频脚本

```
0-3秒：Hook（制造好奇/冲突/共鸣）
3-10秒：产品展示（痛点→解决方案）
10-13秒：使用效果/用户证言
13-15秒：CTA（点击链接/关注/评论）
```

→ 参见 `examples/social-douyin.md`

### LinkedIn 帖子

```
第1行：Hook（数据/洞察/反直觉观点）
第2行：[空行，制造折叠悬念]
正文：故事/案例/洞察展开
结尾：开放式问题（引导评论互动）
```

→ 参见 `examples/social-linkedin.md`

## Quality Checklist

- [ ] 是否适配了目标平台的调性和格式规范？
- [ ] 开头是否有足够的吸引力（3秒法则）？
- [ ] 是否避免了跨平台复制粘贴（一稿多发）？
- [ ] 是否包含了合适的 CTA？
- [ ] 小红书/抖音是否标注了广告（如为商业推广）？
