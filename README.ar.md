# Sidekick

**وكيل ذكاء اصطناعي محلي يعمل على جهاز أندرويد الخاص بك.** ملف بايثون واحد، بلا أي تبعيات خارجية، والمتصفح هو الواجهة.

إنه لا يكتفي بالدردشة — بل **يتحكم فعليًا بجهازك**: قراءة الملفات وكتابتها، تنفيذ الأوامر، تعديل الشيفرة، تصفح الويب، التحكم بهاتفك، إنشاء الجداول، ومعالجة الصور.

> `Sidekick` مجرد اسم افتراضي من المصنع. يمكنك تغييره إلى أي اسم تريده من صفحة «الهوية».

## ما الذي يميّزه عن غيره من وكلاء الذكاء الاصطناعي

### ١. تثبيت سهل للجميع — أمران فقط، بلا خطوة ثالثة

لا حاجة لمعرفة بايثون. لا إعداد بيئة. لا قاعدة بيانات. ثبّت Termux، والصق سطرين، وافتح المتصفح، وانتهى الأمر.

```bash
pkg install -y python curl
bash install.sh
```

بلا Docker، بلا Node، بلا تعارض تبعيات. إنه يستخدم **مكتبة بايثون القياسية فقط**، لذا لا يمكن للتحديثات الخارجية أن تُعطّله — إن عمل اليوم، فسيعمل بعد ثلاث سنوات أيضًا.

### ٢. يتطوّر بنفسه كل يوم — بلا صيانة وبلا تحديث عن بُعد

هذه أغرب ميزة فيه: **يصبح أفضل قليلًا كل يوم، ولا يحتاج أحد إلى أن يرسل لك تحديثًا.**

كل يوم يراجع أداءه، ويجد ما يستحق التحسين، ويجري التعديل، ويكتبه في سجل. هذا عمل حقيقي أنجزه من تلقاء نفسه:

| التاريخ | ما عدّله بنفسه |
|---|---|
| 09-28 | أضاف إلى `list_dir` اقتراحات «الأرشفة حسب النوع» — عند سرد الملفات يخبرك الآن أن الصور مكانها `Pictures/` والمستندات مكانها `Documents/` |
| 09-28 | عند كتابة وسيط أداة بشكل خاطئ، يتجاهل بهدوء الوسائط غير المدعومة ويقترح الاسم الصحيح الأقرب (مثل `cwd` ← `command`) |
| 09-29 | لم يعد `read_file` يُخرج رموزًا مشوّهة مع الملفات الثنائية، بل يبلّغ عن نوع الملف وحجمه |
| 10-01 | ثبّت ارتفاع بطاقة الطرفية — لأن الاختبارات كشفت أن زر «حفظ» كان يتحرك 447 بكسل عند تبديل التبويبات، ما يسبب نقرات خاطئة |

> هذه ليست شعارات دعائية، بل مقتطفات من سجل تطوّره الخاص. وبمجرد تشغيله على جهازك، سيطوّر تحسينات **تخصّك أنت**.

**ماذا يعني هذا:** سيتفرّع وكيلك ووكيل شخص آخر بعد شهر من الاستخدام. إن كنت تطلب منه غالبًا ترتيب ألبومات الصور، فسيطوّر معالجة صور أقوى. وإن استخدمته للتقارير، فسيطوّر مسار عمل مستندي أكثر سلاسة. **كل جهاز يربّي وكيلًا فريدًا من نوعه.**

### ٣. يصلح أخطاءه بنفسه — ويمكنك مشاهدته وهو يشخّص

عندما يتعطل البرنامج، لا يترك أثرًا للمكدّس فحسب. لديه آلية **إصلاح ذاتي** مدمجة: كشف التعطل ← قراءة سجلاته لتحديد الموقع ← إصلاح الشيفرة ← التحقق ← تسجيل النتيجة.

سجل حقيقي (من `selfheal.json`):

```
10-01 14:22  تم كشف تعطّل    سجل المراقب · البصمة f99407371b41
10-01 14:23  اكتمل الإصلاح   تأكيد — السطر 2809 شيفرة قراءة سجلات غير
                             ذات صلة، و tool_wx_auto معرَّف.
                             لا حاجة لمزيد من التعديلات.
```

بل إنه **ينقض استنتاجه الخاطئ**: في عملية إصلاح ذاتي أخرى خلص إلى أن «هذا ليس خطأً يحتاج إصلاحًا — الملف أصلح نفسه بالفعل»، وعرض الأدلة في جدول. إنه لا يعدّل بشكل أعمى.

قبل تعديل نفسه **ينشئ نسخة احتياطية أولًا**، ثم **يجري فحصًا نحويًا**، وإن لم يعمل **يتراجع تلقائيًا**. لذا «إصلاحه لنفسه» لا يعني «تخريبه لنفسه».

### ٤. يستأنف من حيث توقف — المهام الطويلة تنجو من الانقطاع

مهمة استغرقت نصف ساعة وقَتَل نظام أندرويد Termux؟ بعد إعادة التشغيل **يستأنف تلقائيًا**، دون أن تشرح كل شيء من جديد.

```bash
$ tail evolve.log
[إصلاح ذاتي] تم العثور على علامة استئناف صريحة؛ المتابعة تلقائيًا
[إصلاح ذاتي] استئناف 20260928-034008-1058 (boot)، المحاولة 2
```

إعادة تشغيل الهاتف، تغيير الشبكة، إنهاء Termux من قِبَل النظام — إنه يتذكر أين كان.

:::tip بجملة واحدة

**سهل التثبيت، ينمو مع الاستخدام، يصلح نفسه عند العطب، ويستأنف بعد الانقطاع.**

:::

### تحقّق بنفسك — لا تأخذ كلامي على الثقة

بعد التثبيت، انظر إلى سجلات تطوّره الخاصة:

```bash
cat ~/.termux-agent/evolve.json     # ما طوّره لنفسه ولماذا
cat ~/.termux-agent/selfheal.json   # التعطلات التي اكتشفها وأصلحها
tail ~/.termux-agent/evolve.log     # سجل حيّ للتطوّر والإصلاح الذاتي
```

هذه الملفات **يكتبها الوكيل أثناء التشغيل**، وليست مواد دعائية مُعدّة مسبقًا. شغّله لبعض الوقت وستمتلئ بسجلات تخصّك.

## ما هو

مساعد ذكاء اصطناعي يعيش داخل هاتفك أو جهازك اللوحي، يُستخدم عبر واجهة المتصفح.

**خيارات التصميم**

| المبدأ | الشرح |
|---|---|
| **بلا تبعيات خارجية** | يستخدم مكتبة بايثون القياسية فقط؛ يكفي `pkg install python`. لا يلمس أي وحدات أصلية تحتاج إلى ترجمة، لذا لا يمكن للتحديثات الخارجية أن تُعطّله أبدًا |
| **تخزين محلي** | المحادثات والذاكرة والمفاتيح تبقى في `~/.termux-agent/` على جهازك. لا شيء يُرفع إلى السحابة |
| **قادر على تعديل نفسه** | يمكنه تحرير شيفرته المصدرية لإضافة وظائف، ويتراجع تلقائيًا إذا عطّله التعديل |
| **مراقب مدمج** | إذا ماتت الخدمة تُعاد تلقائيًا، دون systemd (غير موجود في أندرويد) |
| **بلا حاجة لتحديثات عن بُعد** | لا خادم ولا دفع تحديثات. تطوّره ذاتي؛ والقدرات الجديدة لا تعتمد على إصدار ينشره المؤلف |

## التثبيت

المتطلبات: تثبيت [Termux](https://f-droid.org/packages/com.termux/) على جهاز أندرويد (**يُنصح بإصدار F-Droid** — يجب أن تتشارك الإضافات توقيع التطبيق الرئيسي).

```bash
# 1. تثبيت بايثون
pkg update && pkg install -y python curl

# 2. من هذا المجلد، شغّل المثبّت
bash install.sh
```

سيقوم المثبّت بالترتيب: فحص البيئة ← نسخ احتياطي لأي تثبيت قائم ← نسخ البرنامج والمهارات ← إنشاء إعدادات افتراضية (**دون الكتابة فوق مفتاح API موجود**) ← تشغيل الخدمة والاختبار الذاتي.

## إعداد مفتاح API

تحتاج إلى مفتاح API في التشغيل الأول. طريقتان:

**الطريقة ١ (مُوصى بها)**: افتح `http://127.0.0.1:8765/` واملأه في «الإعدادات» أعلى اليمين.

**الطريقة ٢**: من سطر الأوامر
```bash
python3 ~/.termux-agent/agent.py config
```

يستخدم DeepSeek افتراضيًا (`https://api.deepseek.com`)، لكن يمكنك توجيهه إلى أي نقطة نهاية متوافقة مع OpenAI — بما في ذلك نموذج محلي على شبكتك.

## الاستخدام اليومي

```bash
bash ~/.termux-agent/start.sh              # استعادة الخدمة بعد إعادة تشغيل Termux
python3 ~/.termux-agent/agent.py doctor    # فحص البيئة + اختبار الاتصال
python3 ~/.termux-agent/agent.py restart   # إعادة تشغيل الخدمة
python3 ~/.termux-agent/agent.py selfcheck # فحص ذاتي (المصدر/المراقب/الخدمة/النسخ)
```

ثم افتح **http://127.0.0.1:8765/** في المتصفح.

### الاستخدام المباشر من سطر الأوامر (بلا واجهة)

```bash
python3 ~/.termux-agent/agent.py "افحص مساحة القرص"   # تشغيل مرة واحدة والخروج
python3 ~/.termux-agent/agent.py -c                  # متابعة المحادثة الأخيرة
python3 ~/.termux-agent/agent.py chat                # دردشة في الطرفية (مبسّطة)
```

### التشغيل التلقائي عند الإقلاع (اختياري)

ثبّت [Termux:Boot](https://f-droid.org/packages/com.termux.boot/)، وافتح التطبيق يدويًا مرة واحدة، ثم:

```bash
python3 ~/.termux-agent/agent.py autostart
```

## نظرة عامة على القدرات

| الفئة | القدرات |
|---|---|
| **عمليات النظام** | تنفيذ أوامر shell، قراءة إعدادات النظام بصلاحيات shell، تثبيت ملفات APK، إدارة العمليات |
| **معالجة الملفات** | قراءة/كتابة/تحرير الملفات، تصحيحات دفعية، تصفح المجلدات، بحث عودي بالتعبيرات النمطية، قراءة مجزّأة للملفات الكبيرة |
| **الشبكة** | جلب صفحات الويب كنص، بحث ويب بلا مفتاح، تنزيل متدفق للملفات الكبيرة |
| **استضافة الشيفرة** | مسار GitHub الكامل (إنشاء مستودع / clone / pull / commit / push / بحث الشيفرة) |
| **التحكم بالأجهزة** | التحكم عن بُعد بهاتف هواوي (بروتوكول HDC)، والعمل على هذا الجهاز بصلاحيات adb shell |
| **معالجة الصور** | إزالة النص أو العلامة المائية، ترميم الصور القديمة، تحسين الجودة، تجميل البورتريه، قصّ الخلفية |
| **إنتاج المستندات** | إنشاء Word / Excel / PPT، تحويل HTML إلى DOCX، قوالب العقود، تحسين التنسيق |
| **إدارة المهام** | قوائم المهام، تفكير متوازٍ بوكلاء فرعيين، طلب قراراتك |
| **التطوّر الذاتي** | تعديل شيفرته المصدرية لإضافة وظائف، مع نسخ احتياطي تلقائي + فحص نحوي + تراجع عند الفشل |
| **مهارات متخصصة** | ٣٦ مستند مهارة تخصصي (الكتابة، التصميم، القانون، المال، التنقيح، …) |

## مرجع الأدوات (٢٠)

### النظام والملفات

| الأداة | الوظيفة | أبرز الميزات |
|---|---|---|
| `bash` | تنفيذ أوامر shell | الأداة الأساسية: تثبيت الحزم، إدارة الملفات، تشغيل البرامج |
| `read_file` | قراءة ملفات نصية (مع أرقام الأسطر) | قراءة مجزّأة للملفات الكبيرة؛ قيمة `offset` سالبة تقرأ السجلات من النهاية |
| `write_file` | كتابة ملف كامل | ينشئ المجلدات الأصلية تلقائيًا |
| `edit_file` | استبدال نصي دقيق | يشترط تطابقًا فريدًا؛ وعند وجود عدة مواضع يبلّغ عن أرقام أسطرها |
| `apply_patch` | تصحيح متعدد المقاطع / الملفات | **ذرّي**: إن لم يتطابق أي مقطع لا يُكتب شيء — بلا تعديلات نصفية |
| `list_dir` | سرد مجلد | يتضمن النوع والحجم ووقت التعديل |
| `grep` | بحث عودي بتعبير نمطي | يُرجع `ملف:سطر: المحتوى` |

### الشبكة

| الأداة | الوظيفة | ملاحظات |
|---|---|---|
| `fetch_url` | جلب صفحة/واجهة كنص عادي | لقراءة النصوص فقط |
| `web_search` | بحث في الويب | **لا يتطلب مفتاح API** |
| `download` | تنزيل متدفق للملفات الكبيرة | بلا قطع، مع مهلة وإعادة محاولة تلقائية. مناسب لملفات APK والمثبّتات |

### الأجهزة والأنظمة الخارجية

| الأداة | الوظيفة | ملاحظات |
|---|---|---|
| `sysshell` | التنفيذ بصلاحيات shell (adb) | صلاحيات أعلى من تطبيق عادي: قراءة إعدادات النظام، `dumpsys`، `getprop`، `pm/am`. **ليس root** |
| `hdcmate` | التحكم عن بُعد بهاتف هواوي | يستخدم بروتوكول HDC (لا adb). `exec` ينفذ أمرًا / `target` يتذكر العنوان / `test` يفحص الاتصال. يتيح أتمتة كاملة للواجهة |
| `github` | التعامل مع مستودعات GitHub | تسعة إجراءات: `list/repo/read/tree/clone/pull/push/create/search`. يتطلب رمزًا |
| `wps` | إنشاء Word/Excel/PPT | منفّذ عبر خدمة MCP محلية، **بلا حاجة إلى حساب**. تُحفظ الملفات في `~/storage/shared/WPS_AI/` |
| `imgedit` | معالجة الصور بالذكاء الاصطناعي | خمس عمليات: `erase` نص/علامة مائية / `restore` صور قديمة / `enhance` الجودة / `beauty` البورتريه / `matting` قصّ الخلفية |

### التعاون والتطوّر الذاتي

| الأداة | الوظيفة | ملاحظات |
|---|---|---|
| `todo_write` | إدارة قائمة المهام | تقسّم المهام من ٣ خطوات فأكثر إلى ٢–٦ بنود تُعرض مباشرة فوق مربع الإدخال؛ وبعد إعادة الاتصال تستأنف من هناك |
| `subagent` | تفكير مستقل لوكيل فرعي | يسلّم مسألة فرعية معزولة إلى وكيل منفصل (بلا وصول إلى الملفات المحلية). مفيد لتوازي المسائل الصعبة |
| `ask_user` | طلب قرارك | يفتح لوحة اختيارات. يُستخدم فقط عند الحاجة إلى قرارك: إنفاق المال، حذف البيانات، الاختيار بين Approaches |
| `selfupdate` | **تعديل نفسه** | نسخ احتياطي تلقائي + فحص نحوي، وتراجع فوري عند الفشل؛ وعند النجاح تُعاد الخدمة تلقائيًا |

### مؤرشف

| الأداة | ملاحظات |
|---|---|
| `wx_auto` | رفيق الرد التلقائي على WeChat (قراءة الشاشة + الرد التلقائي؛ يتطلب تصريحًا وعلم الطرف الآخر). ثلاث بوابات أمان: القراءات غير الواضحة تُسجَّل فقط، ويتخلى عن المهمة إن لم يجد زر الإرسال، وبحد أقصى ٢٠ رسالة في الساعة |

## مكتبة المهارات (٣٦)

المهارات هي **مستندات منهجية تخصصية** تُسلَّم للذكاء الاصطناعي. قبل مهمة ذات صلة يقرأ المهارة المطابقة ويتبع ما فيها من أعراف ودروس مستفادة.

### الكتابة (١١)

| المهارة | الغرض |
|---|---|
| `general-writer` | **مسار احتياطي عام للكتابة (L1).** المستندات الرسمية، التقارير الأسبوعية، المقترحات، البريد، كتابة الإعلانات، المقالات، الإعلام الجديد؛ تقييم جودة بـ ٧ أبعاد + مصفوفة تكييف لـ ١٠ أنواع نصية |
| `academic-paper-expert` | الأوراق الأكاديمية: تصميم البنية، مراجعة الأدبيات، الملخصات، قواعد الاقتباس APA/GB-T7714، الصقل الأكاديمي |
| `tech-blog-expert` | المدونات التقنية: الدروس، تحليل البنية المعمارية، تحليل الشيفرة المصدرية، وثائق المصادر المفتوحة، README |

## ملاحظات أمنية

- الواجهة **تستمع على `127.0.0.1` فقط** ولا تُعرض على الشبكة المحلية (لأن الواجهة تملك صلاحيات تنفيذ الأوامر)
- صلاحيات `config.json` وملفات الرموز هي `600`
- العمليات غير القابلة للتراجع — التهيئة، الكتابة المباشرة على أجهزة الكتل، حذف المجلد الجذري — تُعترض تلقائيًا
- بلا صلاحيات root، ولا يستطيع قراءة البيانات الخاصة لتطبيقات أخرى
- الفحص الذاتي للبيئة: `python3 ~/.termux-agent/agent.py doctor`

## الأسئلة الشائعة

**الخدمة لا تعمل؟**
```bash
python3 ~/.termux-agent/agent.py selfcheck   # انظر ماذا يقول عن نفسه
tail -30 ~/.termux-agent/supervisor.log      # راجع سجل المراقب
```

**هل يتطوّر حقًا بنفسه؟ وماذا عدّل؟**
انظر إلى `~/.termux-agent/evolve.json`؛ كل مدخل يسجّل ما تغيّر ولماذا. اطلاع سريع من سطر الأوامر:
```bash
python3 -c "import json;print('\n'.join(f'{e[\"time\"]}  {e[\"summary\"].splitlines()[0]}' for e in json.load(open('$HOME/.termux-agent/evolve.json'))['log']))"
```

**ما الفرق بين التطوّر الذاتي والتحديث عن بُعد؟**
لا ينزّل أي حزمة تحديث، ولا يوجد خادم يدفع له إصدارات. إنه **يقرأ شيفرته وسجلاته ويعدّلها في مكانها**. لذلك تختلف القدرات بين الأجهزة — الأمر يعتمد على كيفية استخدامك له.

**وإذا عطّل نفسه أثناء تعديل شيفرته؟**
قناة `selfupdate` **تنسخ احتياطيًا أولًا ← تفحص النحو بعد التعديل ← تستعيد فورًا عند الفشل**. وحتى لو عملت الشيفرة الجديدة لكن سلوكها غير سليم، يتراجع المراقب إلى الإصدار السابق. وعملية الإصلاح الذاتي نفسها تترك سجلًا (`selfheal.json`).

**قُتلت مهمة طويلة في منتصفها؟**
بعد إعادة التشغيل تُستأنف تلقائيًا؛ لا حاجة لإعادة الشرح. ستظهر كلمة «استئناف» في السجل.

**عدّلت الشيفرة ولم يحدث شيء؟**
الشيفرة الجديدة لا تصبح فعّالة إلا بعد أن يحمّلها المتصفح مرة واحدة — حدّث الصفحة فحسب.

**أين أرى المزالق التي وقع فيها؟**
يوثّق `skills/termux-traps.md` مزالق البيئة على هذا النوع من الأجهزة.

**كيف أضيف قدرات جديدة؟**
استخدم مهارة `skill-creator` لإنشاء ملف `.md` جديد في `skills/`، أو دع الذكاء الاصطناعي يضيف لنفسه أداة عبر `selfupdate`.
