# Sidekick

**Android 端末上でローカル動作する AI エージェント。** Python ファイル 1 つ、サードパーティ依存ゼロ、UI はブラウザ。

ただのチャットではありません —— **実際に端末を操作します**：ファイルの読み書き、コマンド実行、コード編集、Web 閲覧、スマホ操作、表計算、画像加工。

> `Sidekick` は出荷時のデフォルト名です。「アイデンティティ」ページで好きな名前に変更できます。

**言語：** [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [العربية](README.ar.md)

## 他の AI と何が違うのか

### 1. 誰でも入る簡単インストール —— コマンド 2 行、3 番目の手順はなし

Python の知識は不要。環境構築も不要。データベースも不要。Termux を入れて 2 行貼り付けて、ブラウザを開けば使えます。

```bash
pkg install -y python curl
bash install.sh
```

Docker なし、Node なし、依存関係の衝突なし。**Python 標準ライブラリのみ**を使うので、上流の更新で壊れることがありません —— 今日動けば、3 年後も動きます。

### 2. 毎日自分で進化する —— 手間いらず、リモート更新も不要

ここが一番ユニークな点です：**誰かが更新パッケージを配らなくても、毎日少しずつ賢くなります。**

毎日自分の働きを振り返り、改善点を見つけて直し、ログに書き残します。実際に自分でやった仕事をいくつか：

| 日付 | 自分で直した内容 |
|---|---|
| 09-28 | `list_dir` に「種類別の整理提案」を追加 —— ファイル一覧時に、画像は `Pictures/`、文書は `Documents/` に置くべきだと直接教えてくれる |
| 09-28 | ツール引数の綴り間違いを検出すると、未対応の引数を捨てて正しい近い名前を提案（例：`cwd` → `command`） |
| 09-29 | `read_file` がバイナリファイルで文字化けを吐かなくなり、ファイル種別とサイズを報告するように |
| 10-01 | コンソールのカードを固定高に変更 —— タブ切替時に「保存」ボタンが 447px ずれると実測で判明し、押し間違いが起きていたため |

> これらは宣伝文句ではなく、エージェント自身の進化ログからの抜粋です。あなたの端末で動かせば、**あなたに関係する**改善が育っていきます。

**これが意味すること：** あなたのエージェントと他人のエージェントは、1 か月使うと姿が変わってきます。よくアルバム整理を頼むなら画像処理が進化し、レポート作成に使うなら文書ワークフローが滑らかになります。**端末ごとに唯一無二のエージェントが育ちます。**

### 3. バグは自分で直す —— どう直すかを目の前で見られる

プログラムが落ちても、エラーを残すだけでは終わりません。**自己修復**機構を内蔵しています：クラッシュ検出 → 自分でログを読んで特定 → コードを修正 → 検証 → 記録として保存。

実際の記録（`selfheal.json` より）：

```
10-01 14:22  クラッシュ検出   ウォッチドッグログ · フィンガープリント f99407371b41
10-01 14:23  修復完了        確認済み —— 2809 行目は無関係なログ読み取りコードで、
                             tool_wx_auto は定義済み。これ以上の修正は不要。
```

自分の誤った判断を**覆すことさえあります**：別の自己修復では「これは修正すべきバグではない、ファイルは既に自己修復済み」と結論し、証拠を表で示しました。やたらに書き換えたりはしません。

自分を書き換える前に**必ずバックアップ**し、書き換え後に**構文チェック**を行い、起動しなければ**自動でロールバック**します。だから「自分を直す＝自分を壊す」にはなりません。

### 4. 切断しても続きから —— 長時間タスクも中断に強い

30 分かかるタスクの途中で Termux がシステムに殺された？再起動後、**自動で続きから再開**します。もう一度説明し直す必要はありません。

```bash
$ tail evolve.log
[自己修復] 明示的な再開マーカーを検出、自動でラウンドを継続
[自己修復] 20260928-034008-1058 を自動再開（boot）、2 回目
```

スマホの再起動、ネットワーク切替、Termux のメモリ回収 —— どこまでやったかを覚えています。

---

:::tip 一言でまとめると

**導入は楽、使えば育つ、壊れれば自分で直す、切れても続きから。**

:::

### インストール後すぐ検証できます —— 私の言葉を信じる必要はありません

インストール後、エージェント自身の進化記録を直接見てください：

```bash
cat ~/.termux-agent/evolve.json     # 毎日自分のために何をしたか（理由付き）
cat ~/.termux-agent/selfheal.json   # どのクラッシュを見つけて直したか
tail ~/.termux-agent/evolve.log     # 進化と自己修復のリアルタイムログ
```

これらのファイルは**実行時にエージェント自身が書き込む**もので、あらかじめ入れた宣伝資料ではありません。しばらく動かせば、あなたの記録が育っていきます。

## これは何か

スマホやタブレットの中に住み、ブラウザから使う AI アシスタントです。

**設計上の割り切り**

| 原則 | 説明 |
|---|---|
| **サードパーティ依存ゼロ** | Python 標準ライブラリのみ使用。`pkg install python` だけで動きます。コンパイルが必要なネイティブモジュールに触れないため、上流の更新で壊れることがありません |
| **ローカル保存** | 会話、記憶、キーはすべて端末内の `~/.termux-agent/` に保管。クラウドには送りません |
| **自分を書き換えられる** | 自分のソースコードを編集して機能を追加できます。壊れたら自動でロールバック |
| **ウォッチドッグ内蔵** | サービスが落ちれば自動で起動し直します。systemd に依存しません（Android にはありません） |
| **リモート更新不要** | サーバーも更新配信もありません。進化は自分で行い、機能の成長は作者のリリースに依存しません |

## インストール

前提：Android 端末に [Termux](https://f-droid.org/packages/com.termux/) をインストール（**F-Droid 版を推奨**。アドオンは本体と同じ署名である必要があります）。

```bash
# 1. Python をインストール
pkg update && pkg install -y python curl

# 2. このディレクトリで一括インストール
bash install.sh
```

インストールスクリプトは順に：環境チェック → 既存インストールのバックアップ → プログラムとスキルのコピー → 既定設定の生成（**既存の API キーは上書きしません**）→ サービスの起動とセルフテスト。

---

## API キーの設定

初回実行時に API キーが必要です。2 つの方法：

**方法 1（推奨）**：`http://127.0.0.1:8765/` を開き、右上の「設定」で入力。

**方法 2**：コマンドライン
```bash
python3 ~/.termux-agent/agent.py config
```

既定では DeepSeek（`https://api.deepseek.com`）に接続しますが、OpenAI 互換の任意のエンドポイント —— LAN 内で動くローカルモデルを含む —— に変更できます。

## 日常的な使い方

```bash
bash ~/.termux-agent/start.sh              # Termux 再起動後にサービスを復帰
python3 ~/.termux-agent/agent.py doctor    # 環境チェック＋接続テスト
python3 ~/.termux-agent/agent.py restart   # サービスを再起動
python3 ~/.termux-agent/agent.py selfcheck # 自己点検（ソース／ウォッチドッグ／サービス／バックアップ）
```

その後ブラウザで **http://127.0.0.1:8765/** を開きます。

### コマンドラインから直接使う（UI なし）

```bash
python3 ~/.termux-agent/agent.py "ディスク使用量を確認"   # 1 回実行して終了
python3 ~/.termux-agent/agent.py -c                     # 前回の会話を続ける
python3 ~/.termux-agent/agent.py chat                   # ターミナルで会話（簡易版）
```

### 起動時の自動開始（任意）

[Termux:Boot](https://f-droid.org/packages/com.termux.boot/) を入れ、一度そのアプリを手動で開いてから：

```bash
python3 ~/.termux-agent/agent.py autostart
```

## ツール詳細（20 個）

### システムとファイル

| ツール | 役割 | ポイント |
|---|---|---|
| `bash` | シェルコマンドの実行 | 主力ツール。パッケージ導入、ファイル管理、プログラム実行 |
| `read_file` | テキストファイルの読み込み（行番号付き） | 大ファイルは分割読み込み。`offset` に負の値を渡すとログ末尾から読めます |
| `write_file` | ファイル全体の書き込み | 親ディレクトリを自動作成 |
| `edit_file` | 正確な文字列置換 | 一意な一致を要求。複数箇所ある場合は行番号を提示 |
| `apply_patch` | 複数箇所／複数ファイルのパッチ | **アトミック**：1 か所でも一致しなければ全体を書き換えず、中途半端な適用になりません |
| `list_dir` | ディレクトリ一覧 | 種別、サイズ、更新時刻を含む |
| `grep` | 再帰的な正規表現検索 | `ファイル:行番号: 内容` を返す |

### ネットワーク

| ツール | 役割 | 注意 |
|---|---|---|
| `fetch_url` | Web ページ／API をプレーンテキストで取得 | テキスト読み取り専用 |
| `web_search` | Web 検索 | **API キー不要** |
| `download` | 大ファイルのストリーミングダウンロード | 打ち切りなし、タイムアウト付き、自動リトライ。APK やインストーラに最適 |

### 端末と外部システム

| ツール | 役割 | 説明 |
|---|---|---|
| `sysshell` | shell（adb）権限で実行 | 通常アプリより高い権限。システム設定、`dumpsys`、`getprop`、`pm/am` を読めます。**root ではありません** |
| `hdcmate` | Huawei スマホの遠隔操作 | HDC プロトコル（adb ではありません）。`exec` でコマンド実行／`target` でアドレス記憶／`test` で接続確認。完全な UI 自動化が可能 |
| `github` | GitHub リポジトリの操作 | `list/repo/read/tree/clone/pull/push/create/search` の 9 アクション。トークン設定が必要 |
| `wps` | Word/Excel/PPT の生成 | ローカル MCP サービス実装で、**アカウント不要**。ファイルは `~/storage/shared/WPS_AI/` に保存 |
| `imgedit` | 画像の AI 処理 | 5 種類：`erase` 文字・透かし消去／`restore` 古い写真の復元／`enhance` 画質向上／`beauty` 人物補正／`matting` 切り抜き |

### 連携と自己進化

| ツール | 役割 | 説明 |
|---|---|---|
| `todo_write` | タスクリストの管理 | 3 ステップ以上のタスクを 2〜6 項目に分割し、入力欄の上にリアルタイム表示。切断・再接続後はそこから続行 |
| `subagent` | サブエージェントの独立した思考 | 独立した小問題を別エージェントに委ねます（端末のファイルには触れません）。複数の難点を並行して進めるのに適しています |
| `ask_user` | あなたへの判断の確認 | 選択パネルを表示。あなたの判断が必要なときだけ使用：出費、データ削除、方針の選択 |
| `selfupdate` | **自分を書き換える** | 自動バックアップ＋構文チェック、失敗時は即座に復元。成功するとサービスが自動で再起動 |

### アーカイブ済み

| ツール | 説明 |
|---|---|
| `wx_auto` | WeChat 自動応答（画面読み取り＋自動返信。許可と相手の了解が必要）。三重の安全ゲート：認識が不確かならログのみ、送信ボタンが見つからなければ断念、1 時間あたり最大 20 通 |

## セキュリティについて

- UI は **`127.0.0.1` のみで待ち受け**、LAN には公開しません（UI にはコマンド実行権限があるため）
- `config.json` とトークンファイルのパーミッションは `600`
- フォーマット、ブロックデバイスへの直接書き込み、ルートディレクトリの削除など不可逆な操作は自動的にブロックされます
- root 権限はなく、他アプリのプライベートデータも読めません
- 環境セルフチェック：`python3 ~/.termux-agent/agent.py doctor`

## よくある質問

**サービスが起動しない？**
```bash
python3 ~/.termux-agent/agent.py selfcheck   # 自分がどう言うか見る
tail -30 ~/.termux-agent/supervisor.log      # ウォッチドッグのログを確認
```

**本当に自分で進化する？何を変えた？**
`~/.termux-agent/evolve.json` を見てください。各項目に何をなぜ変えたかが記録されています。コマンドラインで手早く見るには：
```bash
python3 -c "import json;print('\n'.join(f'{e[\"time\"]}  {e[\"summary\"].splitlines()[0]}' for e in json.load(open('$HOME/.termux-agent/evolve.json'))['log']))"
```

**自己進化とリモート更新はどう違う？**
更新パッケージをダウンロードせず、サーバーがバージョンを配ることもありません。**自分のコードとログを読んで、その場で直します。** だから端末ごとに育つ能力が異なり、使い方次第で変わります。

**自分でコードを直して壊したら？**
`selfupdate` 経路では**先にバックアップ → 編集後に構文チェック → 失敗すれば即座に復元**します。新しいコードが起動しても動作がおかしければ、ウォッチドッグが前のバージョンにロールバックします。自己修復の過程自体も記録に残ります（`selfheal.json`）。

**長時間タスクが途中でシステムに殺された？**
再起動後に自動で続きから再開します。説明し直す必要はありません。ログに「自動再開」と出ます。

**コードを変えたのに反映されない？**
新しいコードはブラウザが一度読み込んでから有効になります。ページを再読み込みしてください。

**どんな落とし穴を踏んだか見たい？**
`skills/termux-traps.md` にこの種の端末の環境的な罠が記録されています。

**新しい機能を追加したい？**
`skill-creator` スキルで新しい `.md` を作って `skills/` に置くか、`selfupdate` で AI 自身にツールを追加させてください。
