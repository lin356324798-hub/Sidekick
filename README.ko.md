# Sidekick

**Android 기기에서 로컬로 실행되는 AI 에이전트.** 파이썬 파일 하나, 서드파티 의존성 제로, 브라우저가 인터페이스.

단순한 대화가 아닙니다 — **실제로 기기를 조작합니다**: 파일 읽고 쓰기, 명령 실행, 코드 수정, 웹 탐색, 휴대폰 제어, 스프레드시트 작성, 이미지 편집.

> `Sidekick`은 출고 시 기본 이름일 뿐입니다. 설치 후 '아이덴티티' 페이지에서 원하는 이름으로 바꿀 수 있습니다.

**언어:** [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | **한국어** | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [العربية](README.ar.md)

## 다른 AI와 무엇이 다른가

### 1. 누구나 되는 간단 설치 — 명령 두 줄, 세 번째 단계 없음

파이썬을 몰라도 됩니다. 환경 설정도, 데이터베이스도 필요 없습니다. Termux를 설치하고 두 줄을 붙여넣고 브라우저를 열면 끝입니다.

```bash
pkg install -y python curl
bash install.sh
```

Docker 없음, Node 없음, 의존성 충돌 없음. **파이썬 표준 라이브러리만** 사용하므로 상위 업데이트로 망가질 일이 없습니다 — 오늘 돌아가면 3년 뒤에도 돌아갑니다.

### 2. 매일 스스로 진화 — 관리도, 원격 업데이트도 필요 없음

가장 특별한 점입니다: **누가 업데이트 패키지를 보내주지 않아도 매일 조금씩 더 똑똑해집니다.**

매일 자기 성과를 되돌아보고, 개선할 점을 찾아 고치고, 로그에 기록합니다. 스스로 해낸 실제 작업들:

| 날짜 | 스스로 바꾼 것 |
|---|---|
| 09-28 | `list_dir`에 '유형별 정리 제안' 추가 — 파일 목록을 볼 때 이미지는 `Pictures/`, 문서는 `Documents/`에 넣어야 한다고 바로 알려줌 |
| 09-28 | 도구 인자를 잘못 쓰면 지원하지 않는 인자를 조용히 버리고 가장 가까운 올바른 이름을 제안 (예: `cwd` → `command`) |
| 09-29 | `read_file`이 바이너리 파일에서 깨진 문자를 쏟아내지 않고 파일 유형과 크기를 보고하도록 변경 |
| 10-01 | 콘솔 카드를 고정 높이로 변경 — 탭 전환 시 '저장' 버튼이 447px 움직여 잘못 누르기 쉽다는 것을 실측으로 발견했기 때문 |

> 이건 홍보 문구가 아니라 에이전트 자신의 진화 로그 원문입니다. 여러분의 기기에서 돌리면 **여러분과 관련된** 개선이 자라납니다.

**이게 뜻하는 것:** 여러분의 에이전트와 남의 에이전트는 한 달만 써도 달라집니다. 사진 정리를 자주 시키면 이미지 처리 능력이 진화하고, 보고서 작성에 쓰면 문서 흐름이 매끄러워집니다. **기기마다 세상에 하나뿐인 에이전트가 자랍니다.**

### 3. 버그는 스스로 고침 — 고치는 과정을 지켜볼 수 있음

프로그램이 죽어도 에러만 남기지 않습니다. **자가 치유** 메커니즘이 내장되어 있습니다: 크래시 감지 → 스스로 로그를 읽어 위치 파악 → 코드 수정 → 검증 → 기록 보관.

실제 기록 (`selfheal.json` 발췌):

```
10-01 14:22  크래시 감지    워치독 로그 · 지문 f99407371b41
10-01 14:23  치유 완료      확인됨 — 2809행은 무관한 로그 읽기 코드이고,
                           tool_wx_auto는 정의되어 있음. 추가 수정 불필요.
```

자신의 잘못된 판단을 **뒤집기도 합니다**: 다른 자가 치유에서는 "이건 고칠 버그가 아니라 파일이 이미 스스로 복구된 것"이라고 결론 내리고 증거를 표로 제시했습니다. 함부로 고치지 않습니다.

자신을 고치기 전에 **먼저 백업**하고, 고친 뒤 **구문 검사**를 하며, 실행되지 않으면 **자동으로 롤백**합니다. 그래서 "스스로 고친다"가 "스스로 망가뜨린다"가 되지 않습니다.

### 4. 끊겨도 이어서 — 긴 작업도 중단에 강함

30분짜리 작업 도중 Android가 Termux를 죽였나요? 재시작하면 **자동으로 이어서 실행**합니다. 처음부터 다시 설명할 필요가 없습니다.

```bash
$ tail evolve.log
[자가 치유] 명시적 재개 표시 발견, 자동으로 계속 진행
[자가 치유] 20260928-034008-1058 자동 재개 (boot), 2번째 시도
```

휴대폰 재부팅, 네트워크 전환, Termux가 시스템에 의해 정리됨 — 어디까지 했는지 기억합니다.

---

:::tip 한 줄 요약

**설치는 쉽고, 쓰면 자라고, 고장 나면 스스로 고치고, 끊겨도 이어서 합니다.**

:::

### 설치 후 바로 검증 — 제 말을 믿지 않아도 됩니다

설치 후 에이전트 자신의 진화 기록을 직접 보세요:

```bash
cat ~/.termux-agent/evolve.json     # 매일 자신을 위해 무엇을 했는지 (이유 포함)
cat ~/.termux-agent/selfheal.json   # 어떤 크래시를 찾아 고쳤는지
tail ~/.termux-agent/evolve.log     # 진화와 자가 치유의 실시간 로그
```

이 파일들은 **실행 중에 에이전트가 직접 쓰는 것**이며, 미리 넣어둔 홍보 자료가 아닙니다. 얼마간 돌리면 여러분의 기록이 쌓입니다.

## 무엇인가

휴대폰이나 태블릿 안에 살면서 브라우저 인터페이스로 쓰는 AI 어시스턴트입니다.

**설계상의 선택**

| 원칙 | 설명 |
|---|---|
| **서드파티 의존성 제로** | 파이썬 표준 라이브러리만 사용, `pkg install python`이면 충분. 컴파일이 필요한 네이티브 모듈을 건드리지 않으므로 상위 업데이트로 망가질 수 없습니다 |
| **로컬 저장** | 대화, 기억, 키가 모두 기기 내 `~/.termux-agent/`에 있습니다. 클라우드에 올리지 않습니다 |
| **자신을 수정 가능** | 자기 소스 코드를 편집해 기능을 추가할 수 있고, 잘못되면 자동으로 롤백합니다 |
| **워치독 내장** | 서비스가 죽으면 자동으로 다시 띄웁니다. systemd에 의존하지 않습니다 (Android에는 없음) |
| **원격 업데이트 불필요** | 서버도, 업데이트 푸시도 없습니다. 진화는 스스로 하고, 기능 성장은 제작자의 릴리스에 의존하지 않습니다 |

## 설치

전제: Android 기기에 [Termux](https://f-droid.org/packages/com.termux/) 설치 (**F-Droid 버전 권장** — 애드온은 본체와 서명이 같아야 합니다).

```bash
# 1. 파이썬 설치
pkg update && pkg install -y python curl

# 2. 이 디렉터리에서 원클릭 설치
bash install.sh
```

설치 스크립트는 순서대로: 환경 확인 → 기존 설치 백업 → 프로그램과 스킬 복사 → 기본 설정 생성 (**기존 API 키는 덮어쓰지 않음**) → 서비스 시작 및 자가 테스트.

## API 키 설정

첫 실행 시 API 키가 필요합니다. 두 가지 방법:

**방법 1 (권장)**: `http://127.0.0.1:8765/`를 열고 오른쪽 위 '설정'에서 입력.

**방법 2**: 명령줄
```bash
python3 ~/.termux-agent/agent.py config
```

기본값은 DeepSeek(`https://api.deepseek.com`)이지만, OpenAI 호환 엔드포인트 — LAN에서 돌리는 로컬 모델 포함 — 어디든 지정할 수 있습니다.

## 일상 사용

```bash
bash ~/.termux-agent/start.sh              # Termux 재시작 후 서비스 복구
python3 ~/.termux-agent/agent.py doctor    # 환경 자가 점검 + 연결 테스트
python3 ~/.termux-agent/agent.py restart   # 서비스 재시작
python3 ~/.termux-agent/agent.py selfcheck # 자가 진단 (소스/워치독/서비스/백업)
```

그다음 브라우저에서 **http://127.0.0.1:8765/** 를 엽니다.

### 명령줄에서 바로 사용 (인터페이스 없이)

```bash
python3 ~/.termux-agent/agent.py "디스크 사용량 확인"   # 한 번 실행하고 종료
python3 ~/.termux-agent/agent.py -c                   # 지난 대화 이어가기
python3 ~/.termux-agent/agent.py chat                 # 터미널에서 대화 (간이)
```

### 부팅 시 자동 시작 (선택)

[Termux:Boot](https://f-droid.org/packages/com.termux.boot/)를 설치하고 그 앱을 한 번 직접 연 뒤:

```bash
python3 ~/.termux-agent/agent.py autostart
```

## 기능 개요

| 분류 | 기능 |
|---|---|
| **시스템 조작** | 셸 실행, shell 권한으로 시스템 설정 읽기, APK 설치, 프로세스 관리 |
| **파일 처리** | 파일 읽기/쓰기/편집, 일괄 패치, 디렉터리 탐색, 전체 정규식 검색, 대용량 파일 분할 읽기 |
| **네트워킹** | 웹 페이지 텍스트 추출, 키 불필요 웹 검색, 대용량 파일 스트리밍 다운로드 |
| **코드 호스팅** | GitHub 전체 흐름 (저장소 생성/clone/pull/commit/push/코드 검색) |
| **기기 제어** | 화웨이 휴대폰 원격 제어 (HDC 프로토콜), 이 기기에서 adb shell 권한으로 동작 |
| **이미지 처리** | 문자·워터마크 제거, 오래된 사진 복원, 화질 개선, 인물 보정, 배경 제거 |
| **문서 생성** | Word / Excel / PPT 생성, HTML → DOCX 변환, 계약서 템플릿, 조판 다듬기 |
| **작업 관리** | 할 일 목록, 서브 에이전트 병렬 사고, 핵심 결정 확인 |
| **자기 진화** | 자기 소스를 수정해 기능 추가, 자동 백업 + 구문 검사 + 실패 시 롤백 |
| **전문 스킬** | 36개 분야별 스킬 문서 (글쓰기, 디자인, 법률, 금융, 디버깅 등) |

## 도구 상세 (20개)

### 시스템과 파일

| 도구 | 역할 | 특징 |
|---|---|---|
| `bash` | 셸 명령 실행 | 주력 도구. 패키지 설치, 파일 관리, 프로그램 실행 |
| `read_file` | 텍스트 파일 읽기 (행 번호 포함) | 대용량 파일 분할 읽기, `offset`에 음수를 주면 로그 끝부터 읽음 |
| `write_file` | 파일 전체 쓰기 | 상위 디렉터리 자동 생성 |
| `edit_file` | 정확한 문자열 치환 | 유일한 일치를 요구. 여러 곳이면 행 번호를 알려줌 |
| `apply_patch` | 여러 곳/여러 파일 패치 | **원자적**: 한 곳이라도 안 맞으면 전체를 쓰지 않음 — 반쯤 적용되는 일 없음 |
| `list_dir` | 디렉터리 목록 | 유형, 크기, 수정 시간 포함 |
| `grep` | 재귀 정규식 검색 | `파일:행번호: 내용` 반환 |

### 네트워킹

| 도구 | 역할 | 비고 |
|---|---|---|
| `fetch_url` | 웹 페이지/API를 일반 텍스트로 가져오기 | 텍스트 읽기 전용 |
| `web_search` | 웹 검색 | **API 키 불필요** |
| `download` | 대용량 파일 스트리밍 다운로드 | 잘림 없음, 타임아웃과 자동 재시도. APK·설치 파일에 적합 |

### 기기와 외부 시스템

| 도구 | 역할 | 설명 |
|---|---|---|
| `sysshell` | shell(adb) 권한으로 실행 | 일반 앱보다 높은 권한: 시스템 설정, `dumpsys`, `getprop`, `pm/am` 읽기. **root는 아님** |
| `hdcmate` | 화웨이 휴대폰 원격 제어 | HDC 프로토콜 사용 (adb 아님). `exec` 명령 실행 / `target` 주소 기억 / `test` 연결 확인. 완전한 UI 자동화 가능 |
| `github` | GitHub 저장소 조작 | `list/repo/read/tree/clone/pull/push/create/search` 9가지 동작. 토큰 필요 |
| `wps` | Word/Excel/PPT 생성 | 로컬 MCP 서비스 구현, **계정 로그인 불필요**. 파일은 `~/storage/shared/WPS_AI/`에 생성 |
| `imgedit` | 이미지 AI 처리 | 5가지: `erase` 문자·워터마크 제거 / `restore` 오래된 사진 복원 / `enhance` 화질 개선 / `beauty` 인물 보정 / `matting` 배경 제거 |

### 협업과 자기 진화

| 도구 | 역할 | 설명 |
|---|---|---|
| `todo_write` | 작업 목록 관리 | 3단계 이상 작업을 2~6개 항목으로 나눠 입력창 위에 실시간 표시, 중단·재연결 후 그 지점부터 계속 |
| `subagent` | 서브 에이전트 독립 사고 | 독립된 하위 문제를 별도 에이전트에 맡김 (로컬 파일 접근 없음). 어려운 문제를 병렬로 진행할 때 적합 |
| `ask_user` | 결정 요청 | 선택 패널을 띄움. 반드시 사용자가 정해야 할 때만 사용: 돈 지출, 데이터 삭제, 방안 선택 |
| `selfupdate` | **자신을 수정** | 자동 백업 + 구문 검사, 실패 시 즉시 복원. 성공하면 서비스가 자동 재시작 |

### 보관됨

## 보안 안내

- 인터페이스는 **`127.0.0.1`만 수신**하며 LAN에 노출되지 않습니다 (인터페이스에 명령 실행 권한이 있음)
- `config.json`과 토큰 파일 권한은 `600`
- 포맷, 블록 장치 직접 쓰기, 루트 디렉터리 삭제 등 되돌릴 수 없는 작업은 자동으로 차단됩니다
- root 권한이 없고, 다른 앱의 비공개 데이터도 읽을 수 없습니다
- 환경 자가 점검: `python3 ~/.termux-agent/agent.py doctor`

## 자주 묻는 질문

**서비스가 시작되지 않나요?**
```bash
python3 ~/.termux-agent/agent.py selfcheck   # 자신이 뭐라고 하는지 확인
tail -30 ~/.termux-agent/supervisor.log      # 워치독 로그 확인
```

**정말 스스로 진화하나요? 뭘 바꿨나요?**
`~/.termux-agent/evolve.json`을 보세요. 각 항목에 무엇을 왜 바꿨는지 기록되어 있습니다. 명령줄에서 빠르게 보려면:
```bash
python3 -c "import json;print('\n'.join(f'{e[\"time\"]}  {e[\"summary\"].splitlines()[0]}' for e in json.load(open('$HOME/.termux-agent/evolve.json'))['log']))"
```

**자기 진화와 원격 업데이트는 어떻게 다른가요?**
업데이트 패키지를 내려받지 않고, 서버가 버전을 밀어주지도 않습니다. **자기 코드와 로그를 읽고 그 자리에서 고칩니다.** 그래서 기기마다 자라는 능력이 다르며, 어떻게 쓰느냐에 달려 있습니다.

**자기 코드를 고치다 망가지면요?**
`selfupdate` 경로는 **먼저 백업 → 수정 후 구문 검사 → 실패 시 즉시 복원**합니다. 새 코드가 뜨긴 했지만 동작이 이상해도 워치독이 이전 버전으로 롤백합니다. 자가 치유 과정 자체도 기록을 남깁니다 (`selfheal.json`).

**긴 작업이 중간에 시스템에 의해 종료되면요?**
재시작 후 자동으로 이어서 실행합니다. 다시 설명할 필요가 없습니다. 로그에 '자동 재개'가 표시됩니다.

**코드를 고쳤는데 반영이 안 되나요?**
새 코드는 브라우저가 한 번 로드해야 적용됩니다. 페이지를 새로고침하세요.

**어떤 함정을 겪었는지 보고 싶어요.**
`skills/termux-traps.md`에 이런 기기의 환경 함정이 기록되어 있습니다.

**새 기능을 추가하려면요?**
`skill-creator` 스킬로 새 `.md`를 만들어 `skills/`에 넣거나, AI가 `selfupdate`로 스스로 도구를 추가하게 하세요.
